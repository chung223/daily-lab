# IFE 國際貴賓航班抵達板 (IFE Flight Arrivals)

Retro Airport FIDS 復古機場航班資訊顯示板風格的 IFE 2026 貴賓接待板。

## 簡介

展示 6 個抵達航班（Philippines/Switzerland/Korea×2/Thailand×2）和 1 個出發航班（India）。航班狀態徽章（ARRIVED/DEPARTED）、代表名稱、航厦分配。即時時鐘、系統狀態列、Timeline 展示今日重要事件（VPS Sync/CRM/GitHub/Tech News）。點擊航班觸發彩屑動畫、localStorage 持久化參觀記錄。

## 設計風格

Amber LED × Airport Terminal 琥珀 LED × 機場航站風

- 深夜黑背景 (#0a0a0f)
- 琥珀黃 (#ffcc00) LED 文字
- CRT 掃描線疊加效果
- Orbitron 字體
- 航班號字卡、狀態徽章（綠/黃/紅）

與 06-19 的 Amber CRT BBS 同屬琥珀系但完全不同應用場景（航運 vs BBS）。

## 靈感來源

來自 2026-06-24 記憶的滿滿外國貴賓接送日——🇵🇭 菲、🇨🇭 瑞士、🇰🇷 韓×2、🇹🇭 泰×2 + 🇮🇳 印度送機。把這個真實運作的國際接待任務，做成一個 retro 機場航班顯示板！
