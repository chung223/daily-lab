# 💱 情緒交易所 $EMOTIONS.EX

**Comic Halftone × Stock Exchange 漫畫網點 × 股票交易所風格的情緒交易所**

## 簡介

一個以股票交易所為隱喻的情緒展示與追蹤系統。將焦慮、罪惡感、平靜、喜悅、悲傷等情緒化身為可交易的「情緒期貨」，透過仿漫畫雜誌的網點質感與股票交易所的報價系統，呈現情緒的波動與價值。

## 特色

- 📈 股票交易所介面設計（報價板、漲跌顯示）
- 🎨 漫畫網點 Halftone 質感覆蓋層
- 💹 情緒期貨：焦慮/罪惡感/平靜/喜悅/悲傷
- ✨ 點擊 confetti 彩屑慶祝動畫
- 🖋️ Caveat + Playfair Display + DM Sans 字體組合

## 技術

- 純 HTML/CSS/JS
- confetti.js CDN 動畫
- 無需後端

`experiment` `emotion` `visualization`
