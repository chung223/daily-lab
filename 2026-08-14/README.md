# 🎮 魚油掌機 (Fish Oil Handheld)

Retro Game Boy × Pixel Handheld 復古掌機像素風格的魚油督促小遊戲。

## 特色

- Game Boy 造型主體、經典綠色 LCD 螢幕
- 🐬海豚督導 vs 🦈拖延鯊 動畫對話
- 10 秒計時器挑戰
- 經典台詞輪播
- AB 按鍵 / 鍵盤控制
- localStorage 持久化統計（總劑量/天數/連勝/合規率）

## 設計風格

- Retro Game Boy × Pixel Handheld 復古掌機像素風
- 深夜星空背景 (#1a1a2e→#16213e→#0f3460 漸層)
- Game Boy 灰階機身 (#e8e8e8/#c0c0c0)
- Classic 綠色 LCD 螢幕 (#9bbc0f)
- Press Start 2P 像素字體
- 立體按鍵效果、D-Pad + AB 按鈕組

## 靈感來源

來自 2026-08-13 三色蛋記憶的魚油督導荒謬劇——海豚督導從天花板俯衝，抓包拖延鯊刷了 40 分鐘限時動態，經典台詞「不然我今晚游進你夢裡踢你屁股 🐬💨」。結合過去 8/1 魚油法庭、7/30 魚油合規督察的荒謬傳統，做成一個復古 Game Boy 像素掌機風格的魚油督促遊戲。
