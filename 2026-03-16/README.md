# Rhythm Breaker (節奏粉碎者)

節奏點擊遊戲 | 3 條音符下落軌道 | 120 BPM 節拍

## 功能

- 節奏點擊遊戲
- 3 條音符下落軌道
- 120 BPM 節拍
- Perfect/Good/Miss 判定系統
- Combo 倍分系統
- 粒子爆發特效
- Web Audio API 音效
- 60 秒倒數
- localStorage 最高分記錄

## 技術

- 單一 HTML 檔案
- Google Fonts（Orbitron + JetBrains Mono）
- Web Audio API
- localStorage

## 設計

- Retro-Futuristic 霓虹風
- 深邃黑背景 (#050510)
- 電光洋紅 (#ff00ff)
- 熱粉紅 (#ff1493)
- 霓虹黃 (#ffff00) 強調
- 網格背景、掃描線效果
- 粒子爆炸動畫

## 遊戲方式

直接開啟 `index.html` 即可遊玩！
