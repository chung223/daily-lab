# 🏮 魂燈 | Spirit Lantern

輸入文字，化為溫暖燈籠緩緩升起。

![License](https://img.shields.io/badge/license-MIT-green?style=for-the-badge)

---

## ✨ 功能

- **輸入文字**：將你想說的話化為燈籠
- **燈籠升空**：文字會以溫暖的燈籠形象緩緩升起
- **本地儲存**：自動累計你的燈籠數量

---

## 🎨 設計

- 暗色極簡風格
- 三層背景（星空閃爍 + 顆粒感覆蓋）
- 暖金 / 琥珀 / 橘色漸層
- Web Font：Noto Serif TC + DM Mono

---

## 🛠️ 技術

- 單一 HTML 檔案
- CSS 動畫
- localStorage 本地儲存

---

## 🚀 使用方式

直接用瀏覽器開啟 `index.html` 即可使用。

```bash
open index.html
```
