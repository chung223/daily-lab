# 🧳 出差作戰包 (Mission Prep Kit)

> 互動式出差作戰包，幫你整理思緒、追蹤行李、打包必備物品

![License](https://img.shields.io/badge/license-MIT-green?style=for-the-badge&logo=mit)
![Type](https://img.shields.io/badge/type-工具系-7D9B76?style=for-the-badge)
![Design](https://img.shields.io/badge/design-Paper%20Craft-C67B5C?style=for-the-badge)

---

## ✨ 功能特色

- 📋 **出發前檢查清單** — 可勾選的互動式檢查表，確保不遺漏任何重要事項
- 🌤️ **天氣概況** — 快速查看目的地天氣（需手動輸入）
- ⏱️ **倒數計時器** — 計算距離出發還剩多少時間
- 🎒 **必備物品打包追蹤** — 確認行李已完整打包
- 📝 **作戰筆記** — 記錄重要注意事項
- 💾 **localStorage 持久化** — 所有資料自動儲存，關閉後下次開啟仍在
