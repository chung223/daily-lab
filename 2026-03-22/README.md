# 露珠禪境 | Dewdrop Zen

禪意露珠體驗，輸入思緒化作漂浮露珠，點擊畫面產生漣漪與小露珠，霧氣漂移動畫、樹葉飄動背景、星塵閃爍效果。

## ✨ 功能特色

- 🌧️ **輸入思緒**：輸入文字化為漂浮露珠
- 💧 **點擊互動**：點擊畫面產生漣漪與小露珠
- 🌫️ **霧氣漂移**：多層霧氣緩慢飄動
- 🍃 **樹葉飄落**：樹葉緩慢飄落背景動畫
- ✨ **星塵閃爍**：星空粒子閃爍效果
- 📊 **統計追蹤**：localStorage 統計凝結次數

## 🎨 設計風格

- Zen Garden 禪意花園風
- 深邃暗綠背景 (#0a0f0d)
- 翡翠綠 (#4a8c5e) 與晨露白 (#c8e6ff) 強調色
- 玻璃質感露珠
- 漂浮粒子、發光效果

## 🛠️ 技術棧

- 單一 HTML 檔案
- Google Fonts（Noto Serif TC + DM Mono）
- Canvas API
- localStorage

## 📝 使用方式

直接用瀏覽器開啟 `index.html` 即可體驗。

```bash
open index.html
```
