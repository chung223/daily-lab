# 🌊 漣漪 Ripple Meditation

> 輸入思緒，化為水波漣漪

![Status](https://img.shields.io/badge/status-live-green?style=for-the-badge)
![Type](https://img.shields.io/badge/type-single--html-blue?style=for-the-badge)

## ✨ 功能

- **輸入思緒**：在輸入框中輸入想法，按下 Enter 化為美麗的水波漣漪
- **視覺效果**：暗色水面效果、星空閃爍、顆粒感覆蓋
- **累計計數**：自動儲存產生的漣漪次數

## 🎨 設計

- 暗色極簡風格
- 青綠色強調 (`#5eead4`)
- 三層背景：渐变 + SVG 噪点 + 星空
- 水面反射效果
- Web Font：Noto Serif TC + DM Mono

## 🚀 使用方式

```bash
# 簡單粗暴
open index.html
```

直接用瀏覽器打開 `index.html` 即可使用。

## 📦 技術

- 單一 HTML 檔案
- CSS 動畫
- localStorage 儲存
