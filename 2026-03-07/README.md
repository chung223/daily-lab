## 🎯 功能

- 搞笑許願實現 App
- 點擊蛋形按鈕許願
- 9 種願望類型
- 每種 5+ 種 sarcastic 回應
- GIF 圖片展示
- 許願歷史 localStorage 儲存
- 五彩紙屑動畫

---

## 🛠️ 技術

- 單一 HTML 檔案
- Google Fonts（Cinzel Decorative + Noto Sans TC + ZCOOL KuaiLe）
- CSS 動畫
- localStorage
