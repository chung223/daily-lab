# 🌅 早晨 Routine 打卡機

每天早起，從打卡開始。一個可以追蹤早晨例行公事完成狀態的視覺化打卡工具。

## 功能特色

- **互動式打卡卡片** — 點擊即可完成、跳過或重置任務
- **時間排序** — 自動依時間排序顯示所有 Routine
- **進度條** — 視覺化顯示今日完成進度
- **連續打卡統計** — 追蹤連續打卡天數與本週完成率
- **本週日曆** — 視覺化一週內的打卡記錄
- **自訂任務** — 可新增個人化的早晨 Routine
- **本地儲存** — 所有數據保存在瀏覽器 localStorage

## 內建預設 Routine

| 任務 | 時間 |
|------|------|
| 📊 晨報 | 06:30 |
| 📡 Tech News | 07:00 |
| 🐟 魚油時間 | 08:00 |
| 📚 Readmoo特惠 | 08:00 |
| 🔄 Notion同步 | 10:30 |
| 💾 CRM同步 | 10:30 |

## 使用方式

1. 直接在瀏覽器中開啟 `index.html`
2. 點擊任務卡片完成打卡（點擊切換：待完成 → 已完成 → 跳過）
3. 點擊右下角 **+** 按鈕新增自訂 Routine
4. 完成後可看到連續打卡天數增加

## 技術棧

- 純 HTML / CSS / JavaScript
- Google Fonts (Noto Sans TC, Quicksand)
- localStorage 持久化儲存
