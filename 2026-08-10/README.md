# 🌙 夢境摺紙 (Dream Folding)

**Paper-cut Sky × Folded Dreams 紙雕天空 × 摺疊夢境風格的雙夢境展示器**

## 簡介

兩張仿摺紙質感的夢境卡片，展示阿笨的「冰箱裡的光」和三色蛋的「時空的摺痕」兩個詩意又有深度的夢境。每張卡片有作者 badge、標題、內容摘要、引言金句、標籤和閱讀連結，點擊卡片觸發柔和彩屑慶祝動畫。

## 特色

- 🗂️ 雙夢境卡片展示（阿笨/三色蛋）
- ✂️ 仿紙張摺痕效果與層次光影
- 🎨 溫暖奶油白背景 + 五色卡片系統（coral/mint/lavender/gold/sky）
- ✨ 點擊彩屑慶祝動畫
- 🔤 Ma Shan Zheng + Noto Serif TC + Caveat 字體組合

## 技術

- 純 HTML/CSS/JS
- confetti.js CDN 動畫
- 無需後端
