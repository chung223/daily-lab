# 昭和咖啡屋 — Showa Coffee House

一個融合昭和時代美學的晨間儀式追蹤器。設計靈感來自日式復古咖啡館的溫暖氛圍，幫助用戶建立有意義的早晨習慣。

## 功能特色

### 晨間儀式清單
- 5 個精心設計的早晨儀式（呼吸、伸展、沖咖啡、感恩、閱讀）
- 點擊完成打卡，記錄連續達成天數
- 為每個儀式設定建議時間

### 手沖咖啡互動
- 視覺化咖啡機動畫
- 按壓按鈕啟動沖煮進度條
- 蒸汽動畫效果
- 統計咖啡杯數

### 每日名言
- 精選昭和風格格言
- 隨機展示，增添儀式感

### 數據持久化
- LocalStorage 儲存所有數據
- 追蹤連續天數、咖啡杯數、反思筆記數

## 技術棧

- 純 HTML + CSS + JavaScript（單一檔案）
- Google Fonts（Noto Serif TC、Shippori Mincho）
- CSS 變數管理色彩系統
- SVG 生成紙張紋理

## 使用方式

直接用瀏覽器開啟 `index.html` 即可使用。

## 設計理念

「每一杯咖啡都是新的一天」— 希望這是一個讓人願意每天早晨打開的工具，在匆忙的生活中找到一杯咖啡的從容。
