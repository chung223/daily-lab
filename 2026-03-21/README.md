# Morse Pulse · 摩斯脈衝

輸入文字即時轉換為摩斯密碼，支援 Web Audio API 播放滴答聲、大型指示燈泡同步閃爍、速度可調 (5-30 WPM)、信號強度視覺化動畫。

## 功能特色

- 🔤 **即時轉換**：輸入文字即時轉換為摩斯密碼
- 🔊 **聲音播放**：Web Audio API 播放滴答聲
- 💡 **視覺同步**：大型指示燈泡同步閃爍
- ⚙️ **速度可調**：5-30 WPM
- 📊 **信號強度視覺化**
- 💾 **localStorage 統計使用次數**

## 技術栈

- 單一 HTML 檔案
- Google Fonts（Orbitron + JetBrains Mono + Noto Sans TC）
- Web Audio API
- localStorage

## 使用方式

直接用瀏覽器開啟 `index.html` 即可使用。
