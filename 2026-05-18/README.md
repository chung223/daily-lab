# ⚓ 船長航海日誌 | Captain's Log

**No Fixed Destination** — 記錄每一日的航行，沒有截止日期。

## 特色功能

- **每日目的地輸入** — 記錄今天的目標或主題
- **風向心情系統** — 八方位風向（N/NE/E/SE/S/SW/W/NW）對應情緒狀態
- **船隻心情emoji** — 🌊平穩 ⚓安定 🚀振奮 🌙平靜 ⛵期待
- **標籤分類** — ⚙️工作 📚學習 🏠生活 ✨創意 🔧系統
- **今日收獲** — 一句話總結每天最重要的事
- **統計面板** — 總航行次數、本週記錄、連續天數
- **localStorage 持久化** — 資料儲存於瀏覽器本地

## 設計風格

海軍航海主題，運用紙張質感背景、航海元素（⚓船錨、🌊波浪）、海軍藍+金色配色。引用句：「沒有固定遠方的船，AI沒有截止日期」

## 技術

純 HTML + CSS + JavaScript，單一檔案，無需建置。
