# 🛫 釜山倒數 — Busan Countdown

端午連假出發倒數工具，護照風格卡片設計。

![釜山倒數預覽](preview.png)

## 功能特色

- **護照風格卡片** — 旅行文件感的資訊呈現
- **即時倒數** — 自動計算距離出發的天數
- **航班資訊** — 來回航班詳情一目了然
- **天氣預覽** — 目的地氣候參考
- **行前檢查清單** — 待辦事項可勾選儲存
- **隨機推薦** — 一鍵抽取待辦項目
- **延遲載入動畫** — 漸進式呈現畫面
- **localStorage 持久化** — 勾選狀態自動儲存
