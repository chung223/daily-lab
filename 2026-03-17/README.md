# 星光流 | Starry Flow

許願輸入體驗 | 療癒系互動網頁

---

## 功能

- 許願輸入體驗
- 文字轉化為飄浮星光粒子
- 粒子緩慢上升飄動
- 點擊產生脈動效果
- 多層星雲背景漂移
- localStorage 累計星星計數

## 技術

- 單一 HTML 檔案
- Google Fonts（Cinzel + Noto Serif TC + Noto Sans TC）
- Canvas API
- localStorage

## 設計

- Ethereal Nebula 夢幻星雲風
- 深邃太空背景 (#050510)
- 金色 (#fbbf24)、蜜桃 (#fb923c)、粉紅 (#f472b6)、薄荷 (#34d399)、藍色 (#60a5fa) 星光
- 多層星雲漂移動畫
- 玻璃擬態輸入面板

## 使用方式

直接開啟 `index.html` 即可使用。
