# 🪲 螢火蟲 Firefly

> 輸入文字，化為螢火蟲緩緩升起

![License](https://img.shields.io/badge/license-MIT-green?style=for-the-badge)

---

## ✨ 功能

- 輸入文字，化身為螢火蟲緩緩升起
- 文字飄散效果
- 本地儲存計數（累積發送次數）

## 🎨 設計

- 暗色極簡風格
- 三層背景（星空閃爍 + 顆粒感覆蓋）
- 暖金 / 琥珀 / 橘色漸層

## 🛠 技術

- 單一 HTML 文件
- Web Font（Noto Serif TC + DM Mono）
- CSS 動畫
- localStorage 本地儲存

## 🚀 使用方式

```bash
# 直接開啟 index.html 即可使用
open index.html
```
