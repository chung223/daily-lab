# 數位流星雨 (Digital Meteor Shower)

Matrix 風格數位雨動畫、使用者輸入文字轉化為掉落字符、中文字庫（天地玄黃...）、點擊產生粒子爆發、localStorage 統計（總字數/轉化次數）。

## 功能

- Matrix 風格數位雨動畫
- 使用者輸入文字轉化為掉落字符
- 中文字庫（天地玄黃、宇宙洪荒...）
- 點擊產生粒子爆發
- localStorage 統計（總字數/轉化次數）

## 技術

- 單一 HTML 檔案
- Google Fonts（JetBrains Mono + Noto Sans TC）
- Canvas API
- localStorage

## 設計

- Retro-Futuristic Matrix 風
- 純黑背景 (#000000)
- 經典 Matrix 綠 (#00ff41)
- 熒光青 (#00fff5) 強調
- CRT 掃描線效果
- 字符發光動畫

## 如何使用

直接用瀏覽器打開 `index.html` 即可體驗！

```bash
open index.html
```
