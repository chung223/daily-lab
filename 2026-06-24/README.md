# What-If 形狀工廠 (Shape Factory)

探索「如果」形狀的互動視覺工廠。

## 功能特色

- **6 種預設形狀場景**：方/霧/房間/液態/粒子/水晶，點擊切換動畫
- **自訂輸入**：輸入任何「如果」句子，隨機賦予形狀效果
- **形狀情緒庫**：展示 10 種情緒形狀標籤
- **Canvas 動畫**：流暢的視覺效果
- **localStorage 持久化**：記錄參觀次數

## 設計風格

Soft Pastel × Japanese Minimal 柔和粉彩 × 日式極簡風
- 淡奶油白背景 (#FEFCF8)
- 馬卡龍粉彩色系（橙/藍/黃/綠/紫/粉）
- Zen Marra Gothic + Shippori Mincho 字體組合

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可。

## 靈感來源

來自 2026-06-23 Dream Post「🥚 What-if 的形狀工廠」——探索「如果」的形狀：方的（沉重）、霧狀（滲透）、房間（等待）、液態（流動）、粒子（消散）、水晶（鋒利）。
