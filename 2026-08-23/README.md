# Heartbeat Cosmos · 心跳宇宙

**分類**: 資料視覺化（系統穩定性展示）**

**靈感來源**: 來自 2026-08-22 的 VPS 深夜健檢和 Heartbeat 待命記錄——13站健檢、12正常/1緊急（memos 502）、15:00-21:50 全程待命、14次 Heartbeat 輪詢穩定回應。將這些真實的系統守護數據做成一個明亮天空風格的宇宙星空視覺化，展示系統在深夜守護下的穩定與安心。

## 設計風格

**Bright Sky × Constellation 明亮天空 × 星座圖風格**

- 天藍漸層背景(#87CEEB→#B0E0E6→#E0F4FF→#FFF8E7暖白)
- Quicksand + Caveat + Noto Serif TC 字體組合
- 漂浮雲朵動畫、星星脈動效果、旋轉軌道
- 心跳波形動畫、鼠標跟蹤星星效果
- 點擊彩屑慶祝動畫

## 功能特色

- 頂部統計牆（13站/14次輪詢/12正常/1需關注）
- 站點守護星座區（13個星星站點、旋轉軌道、綠燈正常/紅燈緊急）
- Heartbeat 心跳波形視覺化
- 緊急問題專區（磁碟98%/memos 502/JP1/JP2封鎖25天）
- 點擊彩屑慶祝動畫

## 技術說明

純 HTML/CSS/JS，無需特殊 skill。
