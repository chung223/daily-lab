# 🥘 味道翻譯機 | Flavor Translator

將食物的「感受」翻譯成人人都懂的日常語言。

## 特色

- 輸入食物名稱或風味描述
- 自動翻譯成通俗易懂的表達方式
- 精美的和風紙藝設計
- localStorage 持久化翻譯歷史

## 設計風格

Warm Paper Craft — 溫暖紙藝風格

- 奶油底色 (#FDF8F3)
- 暖棕主色 (#8B6F47)
- 抹茶點綴 (#7A9E7E)
- 櫻花粉 (#E8B4B8)
- 墨金 (#C4A35A)

字體使用 Noto Serif TC、Shippori Mincho、Caveat 搭配呈現。

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可使用。

## 技術棧

- 純 HTML/CSS/JavaScript
- localStorage 本地儲存
- Google Fonts
