# 🌸 寂靜花園 (Sunday Stillness Garden)

明亮花園禪意風格的週日寂靜記錄工具。

## 功能特色

- 🌿 **寂靜指數**（0-100）追蹤
- 💓 **寂靜脈搏次數**記錄
- 📝 **空白時光**記錄
- 🔢 **連續寂靜天數**統計
- ✨ **漂浮花瓣**動畫
- 🌬️ **柔和呼吸**動畫
- 🎊 **彩屑慶祝**動畫
- 💾 localStorage 持久化

## 設計風格

- Light Botanical × Japanese Minimal 明亮植物 × 日本極簡禪意風
- 暖奶油背景 (#FDF9F3 → #EED9C4 漸層)
- 鼠尾草 (#7D9B76) 主色
- 玫瑰 (#E8B4B8) / 金 (#D4A84B) 點綴
- Ma Shan Zheng + Quicksand + Noto Serif TC 字體組合

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可使用。
