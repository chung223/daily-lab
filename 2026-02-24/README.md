# 廢文產生器 (躺平語錄)

點擊產生隨機躺平語錄，複製你喜歡的金句！

## 功能

- 🎲 點擊產生隨機躺平語錄
- 📋 一鍵複製到剪貼簿
- 💾 本地儲存累計計數

## 技術

- React + Vite + TypeScript
- localStorage 儲存

## 設計

- 暗色極簡風格
- 橙色強調色
- 顆粒感背景
- 浮動裝飾圖案

## 執行

```bash
cd daily-lab/2026-02-24

npm run dev
```
