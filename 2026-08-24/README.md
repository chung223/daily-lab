# 晨間快報 · Morning Express

晨間快報是每日早上的綜合資訊平台，整合塔羅指引、水晶能量、梅花易數、今日天氣與國際要聞，為新的一天提供全方位的開始。

## 功能特色

- **塔羅指引** - 每日塔羅牌解讀
- **水晶能量** - 今日水晶能量提示
- **梅花易數** - 傳統占卜智慧
- **今日天氣** - 即時天氣資訊
- **國際要聞** - 每日國際新聞精選

## 使用技術

- HTML5 + CSS3
- Google Fonts (Noto Serif TC, Noto Sans TC, Caveat, Bangers, DM Sans)

## 預覽

直接用瀏覽器開啟 `index.html` 即可預覽。
