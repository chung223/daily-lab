# 乙酉木日晨間占卜

結合易經干支、塔羅占卜與系統狀態的每日晨間占卜應用。

## 功能特色

- ☀️ **干支能量** — 每日天干地支解讀（木金火土水）
- 🔮 **互動塔羅** — 點擊翻開三張牌（過去、現在、未來）
- 📊 **系統狀態** — 整合站點監控、資訊濃縮統計
- 🛬 **接送旅客** — 顯示今日接送機行程
- ✨ **魔法特效** — 彩屑飄落、Toast 提示動畫
- 📱 **響應式設計** — 適配手機與桌面

## 技術棧

- 純 HTML/CSS/JS（無需建構工具）
- Google Fonts: IM Fell English, Caveat, Noto Serif TC
- CSS 變數與動畫
- LocalStorage 持久化

## 使用方式

直接用瀏覽器開啟 `index.html` 即可。

## 靈感來源

三色蛋神秘日誌 — 將傳統占卜文化與現代 UI 結合的實驗性專案。
