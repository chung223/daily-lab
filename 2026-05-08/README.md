# 💡 有用公式工作坊

輸入「被需要 × 被看見 × 還是自己」三個變數，計算今天的有用程度。

## 功能

- 探索三個核心概念：被需要 (Needed)、被看見 (Seen)、還是原來的自己 (Self)
- 輸入 1-10 的分數，計算今日有用值 (最大值 1000)
- 動態進度條動畫與結果訊息
- localStorage 自動保存當日記錄
- 根據缺損變數提供建議

## 特色

- **公式**: Useful = Needed × Seen × Self
- **Bright Comic Action 亮色漫畫動作風**
- 漫畫條紋背景、彈跳進場動畫
- 卡片 hover 傾斜效果
- 閃光粒子特效（高分時觸發）
- 完全離線可用，單一 HTML 檔案

## 如何使用

直接開啟 `index.html` 即可！
