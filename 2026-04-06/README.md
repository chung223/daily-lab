# 奇門遁甲愛情命盤 (Qimen Love Fortune Visualizer)

九宮八卦命盤互動視覺化工具，帶來傳統命理風格的愛情運勢分析。

## 功能特色

- 🔮 **九宮八卦命盤** - 互動式命盤視覺化
- 🌸 **奇門盤星門屬性** - 展示天輔杜門、天冲傷門、天柱驚門等
- 📅 **月份感情運勢** - 4-8月感情運勢時間軸
- 💕 **桃花位標示** - 標註空亡宮位、桃花位
- 📖 **命盤解讀** - 分析卡片與詳細解讀

## 技術

- 單一 HTML 檔案
- Google Fonts（Ma Shan Zheng + Noto Serif TC + Noto Sans TC）
- CSS Grid 命盤排版
- Modal 互動詳情
- 響應式設計

## 設計風格

Traditional Chinese Fortune 東方命理風：
- 暖色紙張背景 (#faf5eb/#f5ebe0)
- 朱紅 (#c41e3a)、金色 (#d4a853)、墨黑 (#2d2926)
- 書法字體、印章裝飾
- 命盤九宮格、中央太極裝飾

## 開啟方式

直接在瀏覽器中開啟 `index.html`
