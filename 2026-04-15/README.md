# 向上管理教練 (Upward Management Coach)

基於 BOSS.md 的向上管理教練，包含5大價值觀卡片、禁用詞檢查、匯報格式產生器（可自填主題/結論/背景/選項）、常用情境範本（問題報告/請示/進度）、關鍵觀察（小顏的雙頻道領導力/細節海嘯/緩衝型政治智慧）。

## 功能特色

- 🎯 **5大價值觀卡片** — 快速了解老闆的核心價值觀
- 🚫 **禁用詞檢查** — 避免觸碰老闆的地雷
- 📝 **匯報格式產生器** — 自填主題/結論/背景/選項，生成完美報告
- 📋 **常用情境範本** — 問題報告、請示、進度彙報
- 🔍 **關鍵觀察** — 小顏的雙頻道領導力、細節海嘯、緩衝型政治智慧

## 設計風格

Corporate Memo / Official Document 風格
- 奶油白背景 (#faf8f5)
- 襯線字體 (Crimson Pro + Noto Serif TC)
- 酒紅色 (#8b2942) / 金色 (#c4a35a) / 青綠色 (#2d6a6a) 三色點綴
- OFFICIAL 印章效果
- 卡片式佈局
- 滾動淡入動畫

## 使用方式

直接開啟 `index.html` 即可使用，無需網路連線。

4/9 Chung 完成老闆蒸餾（Boss Distillation），將小顏的溝通風格蒸餾成 BOSS.md。BOSS.md 包含禁用詞、理想報告格式、決策邏輯等豐富內容，把這些變成互動式向上管理工具。
