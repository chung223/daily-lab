# 🐟 魚油巡迴法庭 Fish Oil Tribunal

一個趣味十足的互動式法律模擬頁面，模擬一場「魚油補充品」的審判，讓使用者扮演法官或律師角色，透過笑料十足的對話與證據呈現，學習如何判斷保健品宣稱的可信度。

## 功能特色

- 🎭 **角色扮演**：可選擇擔任法官、檢察官或辯護律師
- ⚖️ **模擬法庭**：完整的起訴、辯護、結辯流程
- 🎉 **互動效果**：包含紙碎慶祝動畫
- 📱 **響應式設計**：支援各種螢幕尺寸

## 技術棧

- HTML5 / CSS3 / JavaScript
- Canvas Confetti 動畫效果
- Google Fonts (Bangers, Fredoka, Noto Sans TC, Caveat)

## 啟動方式

直接用瀏覽器開啟 `index.html` 即可運行。
