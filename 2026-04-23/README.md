# ⚔️ OCR 勇者冒險 — mlx-ocr 戰鬥系統

> RPG 勇者冒險風格，使用 mlx-ocr 辨識圖片中的文字進行戰鬥互動

## ✨ 功能特色

- ⚔️ **mlx-ocr 文字戰鬥** — 上傳圖片，系統辨識其中的文字作為戰鬥素材
- 🗡️ **角色卡屬性面板** — 速度、精準度、神秘屬性三大戰鬥維度
- 👾 **怪物挑戰系統** — 來自圖片文字的怪物挑戰
- 🛡️ **技能系統** — 多種技能選擇與施展
- 💾 **localStorage 持久化** — 所有資料自動儲存
