# 🏥 VPS Doctor — 主機健康診所

**VPS Doctor** — A medical-themed VPS server health monitoring dashboard. Monitors 9 servers as patient records, displaying vital signs, diagnoses, prescriptions, and real-time status with a warm hospital aesthetic.

## ✨ Features

- **Patient Cards** — 9 servers displayed as patient records with status badges (Healthy ✓, Warning ⚠, Critical ✗)
- **Vital Signs** — Uptime percentage and response time for each server
- **Diagnosis System** — AI-style health assessment for each VPS
- **Prescriptions** — Actionable fix recommendations with terminal commands
- **Uptime Chart** — 7-day uptime trend visualization
- **Quick Actions** — One-click buttons for common operations (health check, restart services, export report)
- **Activity Log** — Real-time event timeline
- **Confetti** — Celebration animations on successful actions

## 🎨 Design

- **Style**: Hospital/Medical
- **Colors**: Hospital Blue (#0066AA), Clinical Red (#DC3545), Clinical Green (#28A745), Warm Paper (#FAFCFC)
- **Typography**: Playfair Display, DM Mono, Noto Sans TC
- **Aesthetic**: Clean clinical interface with friendly medical metaphors
