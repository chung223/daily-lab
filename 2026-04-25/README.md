# 晨間快報 (Morning Express)

報紙頭版風格的晨間快報，展示昨夜 Heartbeat 值勤報告（即時循環狀態、運行時數）、現在時刻、週末待辦勾選清單、距離週一上班倒數。全部資料 localStorage 持久化。

## 靈感來源

凌晨 3:30 的 Daily Lab 時間，今日記憶尚未產生（只有 heartbeat 循環 routine）。結合「凌晨時分 + 週六 + 系統值勤」元素，打造一份清晨報紙風格的值班快報。

## 設計風格

**Saturday Editorial 週六報紙風**
- 奶油白背景 (#FDF9F3)
- 海軍藍 (#1A2B4A) 主色
- 珊瑚紅 (#E85D4C) / 金色 (#D4A84B) / 鼠尾草 (#7D9B76) 點綴
- Playfair Display 襯線字體 + Source Sans 3 + Noto Serif TC
- 編輯卡片式排版、淡入動畫

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可使用。

## 技術

- 純 HTML/CSS/JS（無需特殊 skill）
- localStorage 持久化
