# 命運之弦 | String of Fate

輸入思緒化作宇宙中的震動之弦，弦線自動分布於畫面，點擊弦線觸發共鳴（波動動畫），點擊畫面任意處產生漣漪效果。

## 功能特色

- 🌌 輸入思緒化作宇宙中的震動之弦
- ✨ 弦線自動分布於畫面
- 🔮 點擊弦線觸發共鳴（波動動畫）
- 💫 點擊畫面任意處產生漣漪效果
- 📊 支援多達12條弦線
- 🔄 弦線自動衰減回復靜止狀態
- 📈 localStorage 統計命弦總數與共鳴次數

## 技術栈

- 單一 HTML 檔案
- Google Fonts（Noto Serif TC + DM Mono）
- Canvas API（弦線繪製與波動動畫）
- localStorage

## 設計

Cosmic Clarity 深邃宇宙風：
- 深邃暗背景 (#050508)
- 電光紫 (#8a2be2)、電光青 (#00bfff)、粉紅 (#ff6b9d)、金色 (#ffd700)、翡翠 (#34d399) 隨機弦線色彩
- 星空閃爍背景、星雲漂移效果
- 玻璃質感 UI、噪音覆蓋層、弦線發光效果

## 靈感

每段思緒都是宇宙中的一根弦，穿越時空與他人共鳴。
