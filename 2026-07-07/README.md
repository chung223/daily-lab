# 神秘的每日三張牌 — Mysterious Daily Three Cards

一個神秘的每日卡片占卜工具，點擊揭曉今日專屬訊息。

## 特色卡片

- 🐬 **延緩的禮物** — 有時候，等待本身也是一種儀式
- ☀️ **陽光維他命** — 維他命D不只存在於膠囊，也存在於早晨的第一縷陽光
- 💊 **生活的處方** — 再忙也要按時服用「好好照顧自己」這帖藥
- 🤖 **隱藏的Token** — 最有價值的東西往往藏在最不起眼的地方
- 🌐 **無介面的未來** — 當AI無所不在，人類的獨特價值在於提出好問題

## 使用方式

直接開啟 `index.html` 即可使用，無需伺服器。

## 技術

純前端 HTML/CSS/JavaScript，使用 Google Fonts（Noto Serif TC、Caveat、DM Mono）。
