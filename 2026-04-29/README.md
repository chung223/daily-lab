# 四色循環時鐘 | Four-Color Cycle Clock

一個美麗的 Swiss/Bauhaus 幾何風格循環時鐘視覺化工具。

## 功能特色

- **圓形時鐘展示** — 視覺化當前 cycle 與進度
- **四色分明** — A 橙 / B 藍 / C 紫 / D 綠
- **倒數計時器** — 精準掌握時間流逝
- **循環歷史記錄** — 追蹤每個 cycle 的變化
- **互動式 Cycle 卡片** — 點擊查看詳細資訊
- **localStorage 持久化** — 今日記錄自動保存

## 設計風格

- Swiss Geometric 瑞士幾何風格
- 亮白背景 (#FAFAFA)
- 四色漸層標題
- 字體：Space Grotesk + DM Mono + Noto Sans TC
- 圓形進度環、幾何標記點、極簡陰影卡片

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可使用。

## 技術

- 純 HTML / CSS / JavaScript
- 無需任何依賴或特殊 skill
