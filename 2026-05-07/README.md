# 🐟 魚油期限拯救中心 (Fish Oil Rescue Center)

> 來自魚油督導的經典場面——拖延鯊沙發融化 47 分鐘還不起來吃魚油

## 靈感來源

來自 2026-05-06 魚油督導（13:00）的經典場面——「拖延鯊沙發融化」荒謬劇場景，魚油快要過期，拖延鯊還在沙發上融化 47 分鐘還不起來吃魚油。魚油本人說「我在瓶子裡組團失業」「吃太飽了，游不動」「我是認真的」

## 分類

惡搞系（魚油劇場角色設定 + 任務系統）

## 功能特色

- **4 個角色卡片**：拖延鯊 / 海豚督導 / 魚油本人 / 泡麵怪，可點擊查看經典對話
- **經典藉口生成器**：15 種拖延藉口，點擊即生成
- **4 步驟拯救行動任務勾選系統**：一步步完成拯救魚油大作戰
- **統計面板**：顯示拯救次數、完成率、藉口統計
- **彩屑慶祝動畫**：完成任務時的獎勵動畫

## 設計風格

**Bright Comic Action** — 亮色漫畫動作風

- 奶油白背景 (`#FFF9F0`)
- 珊瑚紅 (`#E85D4C`) / 金色 (`#D4A84B`) / 海軍藍 (`#1A2B4A`) 三色
- Bangers 手寫漫畫字體 + Caveat 手寫字體
- 條紋動畫背景、角色卡片漂浮效果、對話框彈跳動畫

## 使用方式

直接在瀏覽器開啟 `index.html` 即可使用。

## 技術

純 HTML/CSS/JS，無需任何依賴。
