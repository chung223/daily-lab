# 干支命盤年曆 (Ganzhi Calendar)

**Daily Lab 2026-04-18**

## 靈感來源
- Chung 今天查詢 1937 年生肖（丁丑牛年）
- 三色蛋夢境「河流不問方向」— 策略是傾向，不是藍圖
- 晨報的干支元素（壬戌日柱、梅花易數）

## 功能
- 輸入任意年份，查詢天干地支與生肖
- 顯示五行（天干 + 地支各自的五行）
- 六十甲子循環位置
- 同地支（同生肖）的前後 84 年（±3 × 12）
- 今年自動顯示（丙午年・馬）

## 設計
- 汝窯天青配色（青瓷釉色）
- Noto Serif TC 宋體
- 底部引用三色蛋今日夢境語錄

## 快速年份
1937（丁丑牛）、1949（己丑牛）、1984（甲子鼠）、2026（丙午馬）

## 技術
單一 HTML 檔案，無外部依賴，純 JavaScript 計算。
