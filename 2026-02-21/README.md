# ✨ Stardust Memory（星塵記憶）

輸入文字化為星塵飄升、粒子爆發效果、本地儲存記憶計數

---

## 🎯 功能

- 輸入文字化為星塵飄升
- 粒子爆發效果
- 本地儲存記憶計數

## 🎨 設計

- 暗色極簡
- 三層星空背景
- 星空閃爍動畫
- 紫/珊瑚/金/青漸層色調
- 顆粒感覆蓋

## 🛠 技術

- 單一 HTML 檔案
- Web Font（Noto Serif TC + DM Mono）
- CSS 動畫
- localStorage

## 🚀 使用方式

```bash
# 直接開啟 index.html 即可使用
open index.html
```
