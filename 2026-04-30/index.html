第二幕：6 張真實 bug 卡（點一下翻面）
🔴 緊急 WCAG
FAQ Accordion ID 重複
同一頁上多個 FAQ 共用重複 ID，會讓 aria-controls 對應混亂。
點擊翻面看修法
修法
  • 把 FAQ 區塊改成 faq-answer-1 ~ faq-answer-10
  • 同步修正 aria-controls 對應
  • 讓螢幕閱讀器不再迷路
🔴 緊急 A11y
子頁面 Skip Link 重複
6 個子頁面各自帶了重複的 skip link，結構不乾淨又容易重複朗讀。
點擊翻面看修法
修法
  • 刪除重複項，保留清楚的單一入口
  • 讓鍵盤使用者更順
  • 少一點「我到底跳去哪了」的混亂
🟡 重要 SEO
OG URL 全指向首頁
分享 schedule / speakers 等頁面時，社群卡片都像首頁分身。
點擊翻面看修法
修法
  • 每頁設定自己的 OG URL
  • 像 /schedule.html、/speakers.html
  • 分享出去才不會人格分裂
🟡 重要 i18n
韓文機翻痕跡
機翻不只不自然，有時還會讓整體質感掉到地上。
點擊翻面看修法
修法
  • 修正 venue_desc、about_vision_text
  • 士林夜市音譯調整為 Shihlin
  • 內容正確也是 UX
🟢 改善 ARIA
語言切換鈕缺 aria-pressed
按鈕看似可用，但輔助科技不知道現在到底選了哪個語言。
點擊翻面看修法
修法
  • 所有 lang-btn 補上 aria-pressed
  • 互動狀態更清楚
  • 這是細節，但很重要
🔴 致命 JS
script tag 未關閉
看起來只有一行小錯，實際上會讓 JavaScript 整段失效，首頁翻譯一起陪葬。
點擊翻面看修法
修法
  • 補上 ></script>
  • 改成 <script src="js/main.js?v=4" defer></script>
  • Node --check 驗證通過
第三幕：自己救一次 script tag
提示：這裡故意少了很關鍵的東西。
<script src="js/main.js?v=4"
<div class="hero-title">Beyond Ready</div>

正確寫法：
<script src="js/main.js?v=4" defer></script>
<div class="hero-title">Beyond Ready</div>
第四幕：i18n 為什麼會看起來像玄學？
Registration ✅
翻譯正常，代表翻譯資料本身不一定有錯；某些頁面可以跑，某些頁面不行，通常該懷疑「載入流程不一致」。
Home ❌
按鈕看似有反應，但文字沒有替換。這種時候最煩，因為 UI 會演出一種「我有做事喔」的假象。
真相
不是 JSON 壞掉，也不是語言 key 一定漏掉，而是 script tag 沒正確關閉，導致主 JS 沒完整載入。前端世界很多 bug 都是這樣：症狀在 A，病灶在 B。
