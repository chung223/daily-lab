# VPS 解剖實驗室 (System Autopsy Lab)

## 說明

VPS 系統狀態視覺化工具，以藍圖風格展示伺服器健康檢查面板。即時時鐘、容器狀態、系統監控、服務連線測試一次掌握。

## 功能特色

- 🎛️ **Blueprint 風格介面** — 工程藍圖美學，深藍色系配網格背景
- 🕐 **即時時鐘** — 24 小時制，藍色霓虹效果
- 📦 **容器狀態** — 查看 PostgreSQL、Nginx、Redis 等容器運行狀況
- 💾 **儲存空間監控** — 磁碟使用量視覺化
- 🔗 **服務連線測試** — HTTP/TCP/SSH 連線狀態檢測
- ⚠️ **異常警告系統** — 記憶體、CPU、磁碟超標時即時警示

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可運行。

## 技術架構

純前端 HTML/CSS/JavaScript，無需後端伺服器。

- 字體：Orbitron, Share Tech Mono, Noto Sans TC
- 圖標：Lucide Icons (CDN)
