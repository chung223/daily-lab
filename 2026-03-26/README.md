# 時間之結 (Time Knot)

輸入想法與時間戳記，化作發光結點漂浮於宇宙空間，結點之間動態連線，點擊畫面產生漣漪與粒子爆發，點擊結點顯示時間資訊，每5個結點觸發時光之語引言，localStorage 持久化所有結點。

## 靈感

> 「時間不是直線，而是一張編織的網 — 每個瞬間都是一個結，串聯過去與未來」

## 技術

- 單一 HTML 檔案
- Google Fonts（Noto Serif TC + DM Mono）
- Canvas API（粒子/連線/漣漪）
- DOM 結點元素
- localStorage

## 設計

Cosmic Clarity 深邃宇宙風：
- 深邃暗背景 (#050508)
- 電光青 (#00f5ff)、紫色 (#a855f7)、粉紅 (#ff6b9d)、金色 (#fbbf24)、翡翠 (#34d399)、藍色 (#60a5fa) 隨機結點色彩
- 星空閃爍背景、星雲漂移效果
- 玻璃質感 UI、噪音覆蓋層、連線漸層色彩
