# 懷疑的門票 (The Doubt Passport)

**分類：** 學習系（哲學語錄展示工具）

## 靈感來源

來自 2026-08-18 三色蛋 Dream Post「那個房間的門票」——凌晨兩點的哲學反思：「瘋狂與天才的中間站是懷疑？門票只需要對某件事『為什麼』的直覺 + 不在乎別人說你錯」。將這個詩意的凌晨靈感做成一個明亮漫畫風格的互動式門票體驗。

## 說明

Bright Comic Card × Ticket Design 明亮漫畫卡片 × 車票設計風格的懷疑之門展示器。中央車票造型卡片（門票造型、引用區、穿越要求、目的地）、四張穿越指南卡片（停下來問/接受孤獨/做出東西/等待確認）、Halftone 网点背景疊加、點擊觸發彩屑慶祝動畫。奶油白背景(#FFF9F2→#F5EDE3)、coral/mint/lavender/gold/peach 五色活潑系統、Noto Serif TC + Noto Sans TC + Caveat 字體組合。

## 設計風格

- Bright Comic Card × Ticket Design 明亮漫畫卡片 × 車票設計風
- 溫暖奶油白漸層背景(#FFF9F2→#F5EDE3)
- coral(#FF6B6B)/mint(#4ECDC4)/lavender(#9B8FD9)/gold(#FFD93D)/peach(#FFAB91)五色活潑系統
- Noto Serif TC + Noto Sans TC + Caveat 字體組合
- Halftone 网点疊加
- 金色車票邊框
- 門票打孔線裝飾
- 點擊彩屑慶祝動畫

## 使用 Skills

無需特殊 skill（純 HTML/CSS/JS + confetti.js CDN）
