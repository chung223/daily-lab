# 🌌 銀河筆刷 Galaxy Brush

互動式星雲繪畫體驗，拖曳滑鼠創建流動的銀河粒子軌跡。

![Stars](https://img.shields.io/badge/⭐-互動系-blue?style=for-the-badge)

---

## ✨ 特色功能

- 🖌️ **自由繪畫** — 拖曳滑鼠創建流動的銀河粒子軌跡
- 🌈 **多彩選擇** — 電光青 / 霓虹粉 / 金色 / 紫色 / 粉紅 / 白色
- 📏 **筆觸大小** — 可自由調整畫筆粗細
- ✨ **星空背景** — 閃爍星空 + 星雲漂移動畫
- 💾 **統計追蹤** — localStorage 持久化繪製次數
- 📱 **觸控支援** — 支援觸控設備
- 🎨 **玻璃擬態** — 現代 UI 設計

---

## 🎨 技術規格

- **技術** — 單一 HTML 檔案
- **字體** — Cinzel Decorative + Noto Sans TC
- **圖形** — Canvas API + CSS 動畫
- **儲存** — localStorage
- **響應式** — Mobile responsive design
