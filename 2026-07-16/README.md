# 🐬 腸道冲浪 - Dolphin Surf

一個可愛的海豚冲浪小遊戲，在腸道主題的虛擬海洋中冲浪避開障礙物。

## 特色

- 🐬 可愛的海豚角色
- 🌊 動態波浪背景
- 🏖️ 沙灘與海洋漸層場景
- 📊 分數和連擊顯示
- 🎮 直覺的鍵盤/觸控控制

## 使用技術

- 純 HTML5 + CSS3 + JavaScript
- Canvas 遊戲渲染
- Google Fonts (Fredoka, Noto Sans TC, Caveat)
- 響應式設計

## 安裝方式

直接在瀏覽器中開啟 `index.html` 即可遊玩。

## 操作方式

- ⬆️ 上鍵 / W：向上移動
- ⬇️ 下鍵 / S：向下移動
- 空白鍵：開始遊戲 / 重新開始
