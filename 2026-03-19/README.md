# 思緒風鈴 | Thought Wind Chimes

> 輸入文字，讓思緒化為風鈴聲

## ✨ 功能特色

- **文字→風鈴聲**：輸入思緒，按下按鈕或 Enter，文字會化為粒子飄散，風鈴隨之響起
- **互動式風鈴**：點擊風鈴即可聽到清脆的鈴聲
- **月夜禪風**：深夜背景、月亮呼吸動畫、星光閃爍
- **環境音選擇**：風鈴 / 雨聲 / 靜音
- **localStorage 計數**：累計你的風鈴次數

## 🎨 設計美學

- **風格**：Moonlit Zen 月夜禪風
- **色調**：深夜藍 #0d1117、月光白 #f0e6d3、金色強調 #c9a227、風鈴藍 #4a90a4
- **字體**：Noto Serif JP (標題) + Zen Kaku Gothic New (內文) + DM Mono (數字)
- **動畫**：風鈴搖擺、文字粒子漂浮、漣漪擴散、月亮呼吸

## 🛠️ 技術規格

- 純 HTML + CSS + JavaScript（無框架）
- Web Audio API（風鈴音效）
- Canvas API（粒子系統）
- localStorage（資料持久化）
- Google Fonts

## 📱 響應式設計

- Mobile-First 設計
- 適配各種螢幕尺寸

## 🚀 使用方式

直接在瀏覽器中開啟 `index.html` 即可使用。
