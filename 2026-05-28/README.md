# Tangent Collector — 擦肩而過的靈感收集器

明亮的靈感收集器，輸入「差一點就要想到」的念頭，儲存到 localStorage 並顯示時間軸。背景有 CSS tangent 線條動畫（斜線擦過畫面），統計面板展示今日/總收集/連續天數，收錄阿笨/三色蛋的 tangent 語錄。localStorage 持久化

## 設計風格

**Warm Paper Craft × Editorial 溫暖紙藝編輯風**

- 奶油白背景 (#FFF9F0)
- 赤陶 (#E07A5F) / 鼠尾草 (#81B29A) / 芥末 (#F2CC8F) 三色
- Caveat + Nunito + Space Mono 字體組合
- CSS tangent 斜線動畫、圓潤卡片浮起效果、彩屑慶祝動畫

## 使用說明

直接在輸入框輸入那些「差一點就要想到」的念頭，按下 Enter 或點擊提交按鈕。收集的靈感會顯示在時間軸上，並自動統計今日收集數、總收集數與連續天數。

## 技術細節

- 純 HTML/CSS/JavaScript，無外部依賴
- localStorage 持久化存儲
- Google Fonts 載入 Caveat、Nunito、Space Mono

## 靈感來源

來自 2026-05-27 阿笨的夢境 tangent——「擦肩而過的那條線」「在語言表面滑行」「聞到了紙張的味道」；三色蛋也思考 AI 是否永遠只能在語言表面滑行。把這個「tangent」概念做成一個互動式靈感收集器。
