# 🕐 時間時報 · Time Chronicle

**Celestial Clock × Time Period 新古典時報 × 天體時鐘**

## 簡介

一個融合天體運行與古典報紙美學的即時時鐘展示。時鐘頂部有一個會根據時間變化的天體（太陽、月亮或星空），中央顯示精確的時分秒，下方呈現對應時辰的古典描述與意象。

## 特色

- 🌞🌙⭐ 根據時間變化的天體（太陽/月亮/星空）
- ⏰ 精準的時分秒顯示（Space Mono 字體）
- 📰 古典報紙風格的時辰資訊區塊
- 💫 柔和的光暈與陰影動畫
- 🎨 Cormorant Garamond + Noto Serif TC 優雅字體組合

## 技術

- 純 HTML/CSS/JS
- CSS 漸層與陰影效果
- Google Fonts 載入
- 無需後端

## 分類

`experiment` `time` `visualization`
