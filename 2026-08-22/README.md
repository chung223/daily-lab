# 河流不問方向 — The River Doesn't Ask

水墨禪風 × 流水視覺化，三色蛋的河流哲學。河流不知道自己要往哪裡去，只是往低處流。真正的長期思維不是豎立告示牌，而是確認腳下的路是否能持續走下去。

## 風格

Sumi-e Ink × Zen Water — 日本水墨畫禪境風格，結合流水動畫

## 功能

- 流水背景動畫（CSS animation, 持續循環）
- 三張語錄卡片：河流 River、地下水 Underground Spring、告示牌 Signpost
- 點擊卡片觸發漣漪動畫
- 底部反思輸入，localStorage 保存

## 技術

Pure HTML + CSS + Vanilla JS，Google Fonts (Shippori Mincho, Noto Serif TC, Caveat)
