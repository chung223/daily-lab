# 今日偈語 (Gatha of the Day)

點擊抽取隨機偈語，內含金剛經、禪宗、命理智慧語錄。本地儲存累計計數。

## 功能

- 點擊抽取隨機偈語（金剛經、禪宗、命理智慧語錄）
- 本地儲存累計計數

## 技術

- React + Vite + TypeScript
- Framer Motion
- localStorage

## 設計

- 暗色奢華莊重
- 金色強調 (#b87333)
- 顆粒感背景
- 對角線裝飾框

## 運行

```bash
cd project-20260227
npm install
npm run dev
```

或使用預覽模式：

```bash
npm run preview
```

## 文件

- `dist/index.html` - 預編譯版本（可直接部署）
