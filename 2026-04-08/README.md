# 🐟 魚油占卜時光機 (Fish Oil Oracle Machine)

魚油膠囊造型的占卜卡牌、海豚督導荒謬劇風格語錄、12種占卜預言卡（深海智慧/魚油奇蹟/晨曦預兆等）、點擊翻轉膠囊動畫揭示預言、localStorage 歷史記錄追蹤、統計面板（占卜次數/連續天數/魚油提醒天數）、泡泡漂浮背景動畫。

## ✨ 功能特色

- 🐟 **魚油膠囊造型** — 透明魚油膠囊卡牌設計
- 🐬 **海豚督導語錄** — 荒謬劇風格的幽默占卜語
- 🎴 **12種占卜預言** — 深海智慧、魚油奇蹟、晨曦預兆等
- 🔄 **翻轉動畫** — 點擊膠囊翻轉揭示預言
- 📊 **統計面板** — 占卜次數、連續天數、魚油提醒追蹤
- 🫧 **泡泡漂浮** — 海洋風格背景動畫

## 🎨 設計美學

- **風格**: Ocean Oracle 海洋預言
- **配色**: 珊瑚橘 (#FF6B6B) / 海藍 (#4ECDC4) / 沙灘白 (#FFF8E7)
- **字體**: Ma Shan Zheng (書法) + Fredoka + Noto Sans TC

Chung 每天早上 8:30 的「魚油工廠 S.O.P. 海豚督導荒謬劇風格」Discord 提醒 — 把這個變成一個互動占卜工具！結合魚油膠囊 × 塔羅翻牌體驗 × 12種每日預言

直接在瀏覽器中開啟 `index.html` 即可使用，無需任何依賴。
