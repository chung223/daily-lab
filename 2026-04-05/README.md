# 心理健康漫畫故事書 (Mental Health Comic Casebook)

將 12 個心理健康知識庫案例視覺化為漫畫書形式。

## 功能特色

- **四種類型面板**：故事、解方、警訊、洞察
- **左右翻頁漫畫體驗**：流暢的翻頁動畫
- **搜尋功能**：快速找到相關案例
- **標籤分類過濾**：分手康復、依附關係、毒關係、自尊成長、 burnout

## 技術實現

- 單一 HTML 檔案
- Google Fonts：Bangers + Caveat + Noto Sans TC
- CSS 漫畫風格：漫畫格面板、對話框、思考框
- 響應式設計

## 設計風格

Comic Book 漫畫書風格，亮色系背景 (#fef9f3)，珊瑚 (#ff6b6b)、青 (#4ecdc4)、黃 (#ffe66d) 多色點綴。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可使用。

## 靈感來源

Chung 建立的 12 個心理健康知識庫案例檔案，把枯燥的案例變成可翻閱的漫畫故事書。
