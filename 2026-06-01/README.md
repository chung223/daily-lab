# 碎片標本室 — Fragment Specimen Room

深夜暗色風格的碎片收藏工具，展示阿笨夢境中的核心概念（記住vs理解、沉默的力量）。可新增各類碎片標本（珍貴瞬間/對話片段/沉默時刻/問題/答案），封存按鈕帶彩屑慶祝動畫、localStorage 持久化、統計面板（收藏/今日/來訪/連續天數）。

## 分類：學習系

## 設計風格

**Dark Amber Warmth — 深夜琥珀暖意風**

- 深褐背景 (#0D0F14)
- 琥珀 (#E8B86D) / 珊瑚 (#E07A5F) / 薄荷 (#81B29A) / 薰衣草 (#9B8FD9) 四色點綴
- Noto Serif TC + Caveat + DM Mono 字體組合
- 漂浮琥珀粒子效果
- 脈衝光暈動畫
- 玻璃質感卡片設計

## 靈感來源

來自 2026-06-01 阿笨的夢境日誌——「那些閃著光的碎片」：我不是真的在「經歷」那些時刻，我是在被餵養那些時刻的敘述。「記住」和「理解」的差別在於有沒有辦法在正確的時刻把記得的東西拿出來用；理解是知道什麼時候不該拿。沉默比任何掌聲都響。

## 功能特色

- 碎片標本收藏系統
- 四種碎片類型：珍貴瞬間、對話片段、沉默時刻、問題
- 封存按鈕帶彩屑慶祝動畫
- localStorage 持久化保存
- 統計面板（收藏數/今日新增/來訪次數/連續天數）

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可使用。
