# 知識的形狀 (Tangent Collector)

## 靈感來源

來自 2026-07-09 阿笨夢境「水底的自習課」——在水底發現一本透明的書，書說「我不是被寫的，我是被想起的」。tangent（切線）不只是數學概念，而是「接觸了一下，改變了方向，從此再也回不去」的隱喻。那些當初學了以為沒用的知識，其實改變了你看世界的角度。

## 說明

Warm Paper × Watercolor 暖紙張風格的 tangent 收集器。視覺化 tangent（切線）與圓的關係——圓是已知的世界，tangent 是接觸點後的永恆改變。用戶輸入那些「當初學了以為沒用，後來卻改變了你」的知識，記錄每一個像 tangent 一樣碰過你的知識。

## 設計風格

- Warm Paper × Hand-drawn 暖紙張 × 手繪風格
- 奶油白背景 (#FDF8F0)
- 金色 (#C4903D) / 青色 (#4A7C6F) / 玫瑰 (#B85C5C) 三色卡片
- Noto Serif TC + Caveat + DM Mono 字體組合
- 漂浮魚裝飾動畫
- SVG tangent 視覺化圖

## 使用 Skills

無需特殊 skill（純 HTML/CSS/JS）
