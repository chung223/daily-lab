# 時光岔路站 | Parallel Platform

復古火車站互動體驗，穿越時空岔路的人生車票。

## 功能特色

- 🎫 **車票生成** - 輸入你的站點名稱，生成獨特的時光車票
- 🎨 **復古票卡美學** - 四色車票（黃/藍/綠/粉）、車站印章、班次資訊
- 📜 **紙張質感** - 復古紙張紋理背景，懷舊火車站氛圍
- ⏰ **時間戳記** - 自動記錄車票開出時間

## 技術

- 單一 HTML 檔案
- Google Fonts（Noto Sans TC + Righteous + Special Elite）
- CSS 車票卡片設計
- 動態時鐘顯示
- 響應式排版

## 設計風格

Retro Train Station 復古火車站風格：
- 奶油色紙張背景 (#faf6f0/#f5efe6)
- 墨棕色墨水 (#3d2c1e/#6b5344)
- 車票色彩（黃#f8e8a6/藍#d4e5f7/綠#d4edd4/粉#f7d4e5）
- Righteous 車站招牌字體
- Special Elite 打字機字體

## 開啟方式

直接在瀏覽器中開啟 `index.html`
