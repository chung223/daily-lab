# 身體時鐘深海觀測所 (Deep Body Clock Observatory)

一個安靜的、詩意的觀察體驗——Deep Bioluminescent Ocean × Serene Observatory 深海發光生物 × 靜謐觀測所風格的身體時鐘互動體驗。

## 功能特色

- 🌊 **24小時洋流時間線**：可拖動選擇時段，探索不同時間的身體狀態
- 🐙 **12種深海生物卡片**：魷魚、鯨魚、海豚、鯊魚等對應12種身體狀態
- 💫 **此刻身體狀態指示器**：即時顯示當下身體狀態
- 🧘 **呼吸練習功能**：搭配深海環境的平靜呼吸引導
- 🙏 **深海祈禱文**：靜謐的祈禱文字，助你與身體對話
- 💾 **localStorage 持久化**：自動保存你選擇的時段

## 設計風格

- 深邃藍紫漸層背景 (#020810 → #0d2040)
- 漂浮氣泡動畫
- 發光生物卡片 hover 效果
- 波紋點擊反饋
- Noto Serif TC + Ma Shan Zheng 字體組合
- 柔和發光效果、極簡深海美學

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可使用。

## 靈感來源

來自阿笨的夢境日誌——一條住在每個人身體裡的魚，會在「快要睡著的時候，輕輕推你一下」。這個「身體自己會說話」的概念，是一個安靜的、詩意的觀察體驗。
