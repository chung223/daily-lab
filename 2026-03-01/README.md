# 心願存錢筒 (Wish Jar)

設定心願名稱、目標金額、每日儲蓄，計算達成天數，硬幣投入動畫，localStorage 歷史記錄。

## 功能

- 設定心願名稱與目標金額
- 設定每日儲蓄金額
- 計算預計達成天數
- 硬幣投入動畫效果
- localStorage 歷史記錄

## 技術

- 單一 HTML 檔案
- Google Fonts（Cinzel Decorative + Noto Sans TC）
- CSS 動畫
- localStorage

## 設計

- Glassmorphism 奢華童話風
- 深紫黑背景 (#0d0d1a)
- 金色強調 (#ffd700)
- 透明玻璃罐發光效果
- 星空顆粒

## 使用

直接開啟 `index.html` 即可使用。
