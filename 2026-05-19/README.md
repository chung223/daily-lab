# 🥗 午餐辯論俱樂部 (Lunch Debate Club)

漫畫風格的午餐辯論平台，把「吃什麼」的人生難題變成有趣的辯論遊戲。

## 功能特色

- ⚔️ **發起辯論**：輸入兩個午餐選項，開始二選一辯論
- 🗳️ **投票系統**：為心儀的選項投票
- 📊 **統計面板**：追蹤總辯論數、連續天數
- 📜 **裁決歷史**：查看過往辯論記錄
- 💾 **localStorage 持久化**：關閉頁面資料不消失

## 設計風格

**Bright Comic Action 亮色漫畫動作風**
- 奶油白背景 (#FFF9F0)
- 珊瑚紅 (#FF6B6B) / 海軍藍 (#1A2B4A) / 芥末黃 (#FFD93D) 三色對決
- Bangers 手寫漫畫字體 + Caveat 手寫字體
- 對角線條紋背景、卡片懸停浮起效果、彩屑慶祝動畫

## 使用方式

直接在瀏覽器開啟 `index.html` 即可使用。

## 靈感來源

觀察到每天都會遇到「吃什麼」的人生難題（漢堡 vs 拉麵、今天吃這家 vs 那家），結合「選擇困難」情境，打造一個可以把午餐選擇變成有趣辯論的工具。
