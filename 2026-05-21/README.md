# 🏥 漏洞急診室 | Vulnerability ER

漫畫風格急診室，把 5 個 GitHub Issues 做成病患卡片，包含嚴重程度 badge、三格漫畫面板（症狀/危險程度/就醫日期）、護理處方箋、已處理按鈕。localStorage 持久化已處理狀態，彩屑慶祝動畫。

## 設計風格

**Bright Comic Medical** 亮色漫畫醫療風

- 奶油白背景 (#FFF9F0)
- 珊瑚紅 (#FF6B6B) / 橙 (#FF8A6A) / 金 (#FFD93D) 嚴重程度配色
- Bangers 漫畫字體 + Caveat 手寫字體
- 漫畫分鏡卡片、處方箋綠色卡片、浮動動畫效果

## 功能特色

- 🏥 5 個 GitHub Issues 做成病患卡片
- 📋 嚴重程度 Badge（P1/P2/High/Medium）
- 🎨 三格漫畫面板（症狀/危險程度/就醫日期）
- 💊 護理處方箋
- ✅ 已處理按鈕
- 🎉 localStorage 持久化已處理狀態
- 🎊 彩屑慶祝動畫

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可使用。
