# 竹林風禪 (Bamboo Sway)

互動式竹林風體驗 - 滑動/點擊產生微風、竹子搖曳動畫、金色光線效果、落葉粒子飄落、自然環境音 (432Hz)、禪坐計時器、localStorage 累計落葉計數

## 技術

- 單一 HTML 檔案
- Google Fonts（Noto Serif TC + DM Mono）
- Canvas API（灰塵粒子）
- Web Audio API
- localStorage

## 設計

- Japanese Zen 日式禪風
- 深邃森林背景 (#0a1a0a)
- 金色琥珀 (#d4a574)
- 翡翠綠 (#8fbc8f)
- 陽光黃 (#ffd700) 強調
- 光線脈動動畫
- 玻璃擬態控制面板

## 使用

直接用瀏覽器開啟 `index.html` 即可使用。
