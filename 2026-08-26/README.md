# 🫧 系統小窩 · System Pet

一個溫馨的虛擬寵物系統小窩，用純 HTML + CSS + JS 打造。照顧你的系統寵物，餵食、玩耍、睡眠、清潔，看著它開心成長！

## 功能特色

- 🎮 **互動式寵物照顧**：餵食、玩耍、睡眠、清潔多種互動
- 📊 **狀態面板**：即時顯示飽足度、心情、清潔度、活力值
- 📝 **活動時間軸**：記錄寵物的每一個重要時刻
- 🎨 **精美視覺設計**：柔和的珊瑚鼠尾草色彩配置，搭配浮動裝飾動畫
- 📱 **響應式佈局**：支援手機和平板各種螢幕尺寸

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可使用。

## 技術棧

- Pure HTML5
- Pure CSS3（含 CSS Variables、自訂動畫）
- Pure JavaScript（無任何框架或建構工具）
- Google Fonts（Quicksand, Noto Serif TC, Caveat）

## 靈感來源

系統監控工具的卡通化呈現，把冰冷的數據變成可愛的寵物互動。
