# ☯ 易經六十四卦 (I Ching Oracle)

點擊抽取隨機六十四卦，探索古老智慧。

![I Ching Oracle](https://img.shields.io/badge/易經-六十四卦-blue?style=for-the-badge)
![React](https://img.shields.io/badge/React-18+-61DAFB?style=for-the-badge&logo=react)
![TypeScript](https://img.shields.io/badge/TypeScript-5+-3178C6?style=for-the-badge&logo=typescript)

## ✨ 功能

- 🎯 點擊抽取隨機六十四卦
- 📖 顯示卦象與詳細解說
- 💾 localStorage 累計計數
- 🎭 流暢動畫效果

## 🛠️ 技術

- React + Vite + TypeScript
- Framer Motion 動畫
- localStorage 資料儲存

## 🎨 設計

- 暗色奢華莊重
- 金色強調 (#d4af37)
- 顆粒感背景
- 太極符號元素

## 📦 安裝與運行

```bash
cd 2026-02-28
npm install
npm run dev
```

或使用預覽模式：
```bash
npm run preview
```
