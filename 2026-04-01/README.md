## 🎭 專案說明

愚人節特別企劃！一個關於「拖延」和「魚油」的荒謬冒險體驗。

### 主要功能

- ⏰ **魚油保質期倒數計時** — 看著倒數時間，感受時間流逝的壓力
- 📖 **魚油劇場經典回顧** — 那些年，我們一起拖延的日子
- 🎭 **經典台詞生成器** — 輸入任何問題，收穫「魚油式」幽默回應
- 📊 **拖延統計** — 看看今天又浪費了多少時間

### 技術特色

- 純前端單頁應用
- 響應式設計
- 手繪風格 CSS 動畫
- 愚人節限定彩蛋
