# 沉默急診室 — Silent ER

> 「沉默比任何掌聲都響。」 — 那些系統說不出口的話 💀

一個以漫畫風格呈現的系統故障追蹤工具，專門記錄那些「說不出口」的系統問題。

![漫畫風格 UI](https://img.shields.io/badge/style-Comic%20Manga-FF6B6B?style=for-the-badge)
![響應式](https://img.shields.io/badge/responsive-Mobile%20First-4ECDC4?style=for-the-badge)

## ✨ 功能特色

### 📋 沉默病患追蹤
- 卡片式故障顯示，包含緊急度指標
- 康復進度追蹤（localStorage 持久化）
- 漫畫風格進場動畫

### 📊 即時統計面板
- 病患總數 / 已康復數 / 康復率
- 最近檢查時間自動更新

### 💊 康復處方系統
- 系統化治療步驟指引
- 代碼片段高亮顯示
- 處方編號標記（R1, R2...）

### 🎉 視覺體驗
- 漫畫網格背景
- 彩屑慶祝動畫（康復觸發）
- 漂浮漫畫元素裝飾
- Bangers + Caveat 手寫字體

## 🎨 設計元素

| 元素 | 用途 |
|------|------|
| 珊瑚色 `#FF6B6B` | 失敗/緊急狀態 |
| 金黃色 `#FFD93D` | 陰影/強調 |
| 薄荷色 `#4ECDC4` | 康復/成功狀態 |
| 海軍藍 `#1A2B4A` | 主色調/文字 |
| 奶油白 `#FFF9F0` | 背景色 |

## 🛠️ 技術棧

- **純 HTML/CSS/JS** — 零依賴，即開即用
- **CSS 動畫** — fadeIn、float、confetti
- **localStorage** — 康復狀態持久化
- **Google Fonts** — Bangers, Caveat, Noto Sans TC

## 📖 使用方式

1. 直接在瀏覽器開啟 `index.html`
2. 點擊「開始治療」按鈕康復病患
3. 觀賞彩屑慶祝動畫
4. 统计数据自动更新
