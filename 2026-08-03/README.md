## 說明

Warm Editorial × Gallery Card 亮色編輯卡片風格的大使畫廊與站點收藏系統。

- 九位代表卡片展示國籍與站點數量
- 五十一站按類別分類（送機/國際農水/年會/接送機）
- 點擊站點觸發彩屑慶祝動畫
- localStorage 持久化收集進度

- **特效**：編輯格線卡片、彩屑慶祝動畫、localStorage 持久化收集進度
