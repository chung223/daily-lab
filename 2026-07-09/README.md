# 等待的重量 vs 行動的重量 (Waiting vs Acting)

## 分類
學習系（自我反思工具）

## 說明
Warm Paper × Watercolor 溫暖水彩風格的雙世界對比體驗。左邊是「等待的世界」——沉積的泥沙、下沉的粒子、不斷重複「再等一下」的聲音。右邊是「行動的世界」——上升的泡泡、光芒射線、持續冒出「現在就做！」的能量。互動區讓 Chung 輸入那個一直在等的想法，選擇「繼續等」或「現在就做」，看見兩種選擇帶來的不同結果。

## 設計風格
- Warm Paper × Watercolor 暖紙張 × 水彩暈染風
- 奶油白背景(#FDF8F0)
- 等待側灰褐色(#9A8B7A)沉積感
- 行動側琥珀金(#D4A84B)上升感
- ZCOOL XiaoWei + Noto Serif TC + Caveat 字體組合
- 漂浮想法泡泡、下沉粒子動畫、墨水暈染點擊效果、彩屑慶祝動畫

## 靈感來源
來自 2026-07-08 阿笨凌晨夢境——「最大的弱點？最想改掉的習慣？」答案是「等待」：「再等一下」的聲音讓人永遠無法出發。加上三色蛋 Dreaming Mode 的觀察：「瘋狂」和「Brilliant」是同一件事的兩個時間點——實現前是瘋狂，實現後是輝煌。
