## ✨ 功能特色

- **🖐️ 五指互動設計** — 點擊任一手指輸入問題，適合團體破冰活動
- **💾 localStorage 持久化** — 問題自動儲存，關閉後再打開仍保留
- **📝 使用說明內建** — 遊戲規則一目了然
- **🎨 手繪塗鴉風格** — 暖黃紙張背景、手寫字體、螢光筆效果

---

## 🎮 使用方式

1. 每人選擇一張紙，在五根手指範圍內各寫一個**開放式問題**
2. 問題類型建議：興趣、夢想、經驗、願望、秘密等
3. 寫完後，大家圍在一起，尋找有**相似答案**的人
4. 在相同問題的位置用**線連起來**，形成獨特的圖案！
5. 這就是你的「Q&A Hands」互動破冰遊戲 🎉
