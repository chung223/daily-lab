# ✈ VPS Station Board — 主機航班看板

VPS 主機狀態監控面板，航班看板式復古風格。

![Preview](https://img.shields.io/badge/預覽-Demo-blue?style=for-the-badge&logo=rocket)

## ✨ 功能特色

- **16 個站台狀態顯示**（12 online / 4 offline）
- **航班看板式排版** — 復古機場時刻表美學
- **狀態指示燈** — 脈衝動畫即時反映狀態
- **點擊查看詳情** — SSL 狀態、問題描述、修復建議
- **即時時鐘** — VT323 像素字體
- **統計面板** — 上線率、總數即時更新

## 🎨 設計風格

**Retro Airline Departure Board** — 復古航班看板風

- 深色背景 `#1a1a1a`
- 琥珀色標題 `#f0a830`
- 綠/紅狀態燈 `#4ade80` / `#f87171`
- 掃描線覆蓋效果
- 字元風格火車時刻表美學
- Google Fonts：VT323 + Orbitron + Noto Sans TC

## 💡 靈感來源

Chung 昨天下午 VPS 夜班站點健檢（12/16 上線），4 個站台離線含 `SSL_ERROR_SYSCALL`，提案修復 SSL 問題與新增 Security Headers。

## 🛠 技術栈

- 單一 HTML 檔案
- Google Fonts（VT323 + Orbitron + Noto Sans TC）
- CSS 動畫（翻牌進場 / 狀態脈衝）
- Grid 排版
- Modal 詳情面板

## 🚀 使用方式

直接用瀏覽器開啟 `index.html` 即可使用。
