# 虛空蓮 | Void Lotus

互動式蓮花召喚體驗、點擊產生花瓣與粒子爆發、滑鼠移動產生微量粒子軌跡、漣漪擴散效果、localStorage 累計計數

## 🎨 設計

- 虛空蓮花風
- 深邃太空背景 (#050508)
- 粉紅 (#ff6b9d)、青色 (#00f5ff)、紫色 (#a855f7)、金色 (#fbbf24) 漸層
- 星空閃爍、星雲漂移、噪點覆蓋

## 🛠️ 技術

- 單一 HTML 檔案
- Google Fonts（Noto Serif TC + DM Mono）
- Canvas API
- localStorage 持久化

## 🚀 使用方式

直接用瀏覽器開啟 `index.html` 即可體驗。
