# 意外連結星圖 ✨

把夢境中的 8 個意外連結概念做成可點擊探索的星圖。

## 概念

- 珊瑚 ↔ 骨頭
- 群論 ↔ 拱門
- 病毒 ↔ 游離程式碼
- 睡眠 ↔ 網路拓撲

## 靈感

> 「意外是認知框架不夠大」
> — 2026-04-25 三色蛋夢境

凌晨兩點的連結狂想，把那些看起來不相關的事物用星圖的方式連接起來。

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可。

## 設計特色

- Canvas 連線效果呈現概念之間的連結
- 卡片點擊展開顯示連結解釋與經典語錄
- 奶油白背景 (#FFF9F5)
- 珊瑚紅 (#E85D4C) / 海軍藍 (#1A2B4A) / 金色 (#D4A84B) 點綴
- Playfair Display + Noto Sans TC 字體
