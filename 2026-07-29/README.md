# 夏夜祭典 撈金魚｜Summer Festival Goldfish Scoop

**Type:** game

## 簡介

夏夜祭典風格的撈金魚小遊戲。體驗日本夏季祭典（祭典）的歡樂氛圍，在美麗的夜空下使用紙網撈金魚。

## 特色

- 🌙 夏夜星空背景，帶有閃爍星星動畫
- 🏮 紅色燈籠漂浮動畫效果
- 🐟 多種金魚角色（橙、白、花、三色）
- 📱 響應式設計，支援觸控操作
- ✨ VHS 復古膠片風格效果

## 技術

- 純 HTML/CSS/JavaScript
- 無外部依賴（除 Google Fonts）
- CSS 動畫效果
- 觸控友善

## 靈感來源

日本夏季祭典（夏祭）的傳統撈金魚（和金魚すくい）遊戲，結合現代復古美學。
