# 🌳 思維花園 (Thought Garden)

種植每日智慧種子的花園視覺化工具。

## ✨ 功能特色

- **🌱 智慧播種**：輸入今日學習內容與概念標籤，種下智慧種子
- **🌲 五種樹種**：橡樹、松樹、櫻花、柳樹、銀杏，各有獨特 SVG 視覺化
- **📖 知識花園**：點擊任意樹木查看詳細內容
- **🗑️ 整理功能**：支援刪除不需要的記錄
- **💾 持久化儲存**：localStorage 保存所有播種記錄
- **📊 統計面板**：追蹤播種總數、概念標籤數量、連續播種天數

## 🎨 設計風格

Botanical Paper 植物紙藝風
- 奶油白背景 (#faf7f2)
- 鼠尾草綠 (#8fae8b)
- 赤陶 (#c4785a)
- 金色 (#d4a853)

## 🛠️ 技術棧

- 單一 HTML 檔案
- Google Fonts (Caveat + Noto Sans TC + DM Mono)
- SVG 樹種視覺化
- CSS 動畫（搖擺/浮現）
- localStorage 持久化

## 🚀 使用方式

直接用瀏覽器開啟 `index.html` 即可使用。
