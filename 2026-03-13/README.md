# System Pulse Monitor (系統脈衝監控)

系統健康儀表板 / System Health Dashboard

## 功能 Features

- 系統健康儀表板
- 即時時鐘顯示
- 磁碟空間視覺化
- 網路狀態監控
- 連線延遲顯示
- 系統運行時間
- 快捷筆記功能
- 工作階段日誌
- localStorage 持久化

## 技術 Tech

- 單一 HTML 檔案
- Google Fonts（Orbitron + JetBrains Mono + Noto Sans TC）
- CSS 動畫
- localStorage

## 設計 Design

- Holographic HUD 全息風
- 深邃太空背景 (#030712)
- 電光青 (#06b6d4)、紫色 (#a855f7) 強調
- 玻璃擬態卡片
- 網格背景
- 掃描線效果
- 發光動畫

## 如何使用 How to Use

直接開啟 `index.html` 即可使用。
