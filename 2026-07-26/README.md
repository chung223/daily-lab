# 週日早晨電視機 (Sunday Morning CRT)

**分類**: 工具系（自我回顧工具）

**風格**: Warm Retro CRT TV 溫暖復古陰極射線管電視機風格

## 描述

將一週五天化身為五個電視頻道，轉動旋鈕或點擊遙控器切換頻道，體驗 VHS 靜態雜訊、掃描線、琥珀色發光字等懷舊電視效果。每個頻道展示當天的重點事件（Wiki Cycle/AI趨勢/科技濃縮），VT323 像素字體搭配琥珀/深棕暖色調。

## 設計特色

- 深棕背景(#2D1810/#1A0F0A)襯托琥珀光(#FFB347/#FF8C00/#FFCC66)
- SANYO 品牌框架
- 天線與燈泡脈衝光
- VHS 靜態雜訊疊加
- CRT 掃描線效果
- VT323 + Noto Sans TC 字體組合
- 旋鈕/遙控器互動

## 靈感來源

W30 剛完成（2026-07-21~25），包含 Wiki 樂團/豆漿店/AI 頭版/科技超市等多個與 Wiki Cycle 和知識攝入相關的項目；週日 3:30 AM 的寧靜時刻，適合一個懷舊的電視機體驗
