# 時間調酒師 — Time Bartender

你是自己的時間調酒師。

如果時間是黏稠的液體，我們每個人都是自己的時間調酒師。選擇你今天的時間配方，讓這杯特調訴說你的故事。

## 功能特色

- 🌅 **四種時間口味**：清晨薄霧、午后陽光、暮色紫羅蘭、深夜靜謐
- 🎚️ **黏稠度滑桿**：調整時間流逝的速度（從如水到如瀝青）
- 🍸 **動態調酒視覺化**：選擇配料後即時看到酒杯液體層次變化
- ✨ **15種獨特配方**：不同配料組合產生不同的調酒名稱與描述
- 📜 **調酒紀錄**：保存最近10杯的歷史記錄
- 🎊 **慶祝動畫**：完成調製時的彩紙特效

## 靈感來源

2026-06-20 的夢境：「如果時間是液態的」

夢中場景：時間是一條緩慢流動的液態河流，人們用特殊的杯子盛裝。螞蟻在搬家，遠處有湯屋風格的時鐘塔。

## 技術實現

- 純 HTML/CSS/JavaScript（無外部框架依賴）
- Google Fonts：Noto Sans TC、Caveat、Playfair Display
- CSS 動畫：浮游粒子、倒酒動畫、漣漪效果、彩紙飄落
- LocalStorage 持久化調酒紀錄

## 開啟方式

直接用瀏覽器打開 `index.html` 即可。
