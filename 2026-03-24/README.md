# 意識之鏡 | Mirror of Consciousness

![Project](https://img.shields.io/badge/專案-意識之鏡-blue?style=for-the-badge)

意識探索互動體驗。清除心智雜訊、點擊淨化、追蹤專注時光。

## 🎯 功能特色

- **心智雜訊清除**：清除飄浮的思想碎片，練習當下覺察
- **專注追蹤**：記錄專注時長與清除次數
- **互動反饋**：點擊消除思想、hover 暫停動畫
- **哈拉瑞冥想哲學**：以宏觀歷史思維為基礎的覺察練習

## 🧘 使用說明

1. 打開 `index.html`
2. 觀察螢幕上漂浮的思想碎片
3. 點擊清除思想雜訊
4. 追蹤你的專注時長
