# 健康報告卡 2026-04-07 | Blood Test Report Card

血液檢驗報告單設計風格視覺化，以精美的報告卡形式呈現健康數據。

## ✨ 特色

- 📊 報告卡式精美設計
- 🎨 奶油白配暖色調字體
- 📈 數值儀表板與正常範圍顯示
- ✅/⚠️ 狀態標籤（正常/警示/危險）
- 💡 健康建議提示

## 📋 檢驗項目

- **丙氨酸氨基轉移酶 (ALT)** — 肝臟健康指標
- **腎絲球過濾率 (eGFR)** — 腎臟功能評估
- **肌酸激酶 (CK)** — 肌肉健康指標
- **總膽固醇 (TC)** — 血脂評估
- **低密度脂蛋白 (LDL)** — 壞膽固醇
- **高密度脂蛋白 (HDL)** — 好膽固醇（未檢測）
- **空腹血糖 / 糖化血色素** — 血糖控制（未檢測）

## 🎨 設計風格

- 報告單美學：奶油白底 + Playfair Display 襯線字體
- 珊瑚色/金色/鼠尾草綠色 配色
- 狀態指示：綠色（正常）/ 黃色（警示）/ 紅色（危險）
- 柔軟陰影與圓角卡片
