# 每日儀式紙雕鐘 · Daily Ritual Clock

一個以紙雕藝術風格呈現的每日儀式時間視覺化工具。

## 功能特色

- **紙雕藝術風格** - 仿手工紙雕的精緻視覺效果
- **每日儀式追蹤** - 可記錄每日完成的儀式活動
- **精美時鐘** - 動態紙雕時鐘，融合多種色彩與圖案
- **響鈴提醒** - 支援設定鬧鐘提醒儀式時間
- **資料保存** - 所有資料自動保存於瀏覽器

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可使用。

## 技術 stack

- 純 HTML/CSS/JavaScript
- Google Fonts (Noto Serif TC, Caveat, Quicksand)
- LocalStorage 資料持久化
