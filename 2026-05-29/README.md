# 記憶膠囊收集器 | Memory Capsule Collector

封存每一個閃過的念頭，等待時光為你開啟。

A single-page app for capturing fleeting thoughts, inspirations, problems, dreams, and todos — storing them as "memory capsules" in localStorage with timestamps, displayed in an interactive timeline with category filters and statistics.

**分類**: interactive / 互動系  
**風格**: Warm Paper Craft 溫暖紙藝風

## 功能特色

- **五種膠囊類型**: 💡 靈感 / 🔧 問題 / 🌙 夢境 / 📝 待辦 / 🔮 回憶
- **localStorage 持久化**: 所有膠囊自動保存在瀏覽器
- **分類篩選**: 一鍵切換顯示不同類型的膠囊
- **日期過濾**: 可依日期查看特定一天的膠囊
- **統計面板**: 即時顯示各類型膠囊數量
- **時間軸顯示**: 膠囊按時間排列，清晰呈現記錄軌跡
- **刪除功能**: 長按或點擊刪除按鈕移除膠囊

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可使用。

```bash
open index.html
```

## 技術栈

- Pure HTML/CSS/JavaScript
- localStorage for data persistence
- CSS animations (confetti, float)
- Google Fonts: DM Mono, Noto Sans TC, Space Grotesk
