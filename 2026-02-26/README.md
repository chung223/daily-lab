# 月影 (Moon Shadow)

輸入文字，化作月亮的影子。

![Moon Shadow](https://img.shields.io/badge/License-MIT-blue)

## 功能

- 輸入文字化為月亮影子效果
- 文字向右上偏移飄動
- 本地儲存投射計數

## 技術

- 單一 HTML 檔案
- Web Font（Noto Serif TC + DM Mono）
- CSS 動畫、localStorage

## 設計

- 暗色極簡
- 月亮本體 + 光暈
- 星空閃爍
- 顆粒感覆蓋
- 金色強調

## 使用方式

直接用瀏覽器開啟 `index.html` 即可使用。

```bash
# 或啟動本地伺服器
python3 -m http.server 8080
# 然後訪問 http://localhost:8080
```
