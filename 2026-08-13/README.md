# 晨間御守 (Morning Amulet)

Japanese Omamori × Shrine Paper 神社御守 × 和紙質感風格的每日晨間運勢展示器。

## 特色

- 7張命理卡片：干支命理、塔羅、天氣、梅花易數、行程、星座、水晶
- 每張卡片包含 icon、標題、內容和標籤
- 點擊卡片觸發彩屑慶祝動畫
- 溫暖米白背景 (#fdf8f3 → #f5ebe0)
- 朱紅(#c41e3a) + 金(#d4a574) + 墨綠(#2d5a5a) 五色系統
- 和紙質感疊加、浮動符號動畫

## 字體

- Noto Serif TC
- Shippori Mincho
- Kaisei Decol

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可。
