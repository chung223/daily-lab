# 🧠 Memory Echo 記憶迴聲

*記憶是幻想工廠 — 哈拉瑞*

記憶配對遊戲，結合故障藝術風格的視覺效果。

## ✨ 功能特色

- 🃏 **記憶配對** — 經典翻牌遊戲，16種獨特符號
- ⚡ **故障效果** — 翻牌時產生故障特效
- 💥 **爆炸動畫** — 配對成功金色爆炸
- 🔴 **失敗閃爍** — 配對失敗紅色閃爍
- ⏱️ **計時計步** — 計時器 + 步數計數
- 🏆 **最佳成績** — localStorage 儲存本地紀錄

## 🎨 設計風格

- **Glitch-Abstract 故障藝術風**
- 深邃虛空背景 (#050508)
- 電光青 (#00f5ff) + 霓虹紫 (#ff00ff)
- 金色 (#ffd700) 強調
- CRT 掃描線、噪點顆粒、漂浮粒子

## 🛠️ 技術

- 單一 HTML 檔案
- Google Fonts（Orbitron + JetBrains Mono）
- CSS 動畫
- localStorage 持久化

## 🚀 使用方式

直接用瀏覽器開啟 `index.html` 即可遊玩。
