# 🎛️ IFYE 2026 — Station Commander

International Four-H Youth Exchange 虛擬電台監控中心。即時掌握 9 位 Delegate、51 個 Station、6 個國家的 VPS 營運狀態。

## 功能特色

- **即時狀態追蹤** — 顏色區分（綠/黃/紅）顯示各站點上線/警告/離線狀態
- **Delegate 管理** — 點擊展開各代表負責的所有站點
- **站點備註** — 可對每個 Station 留言記事，自動產生時間線
- **三種檢視模式** — 清單視圖、網格卡片、時間線
- **即時時鐘** — 顯示 UTC 時區與當地時間
- **數據統計** — Header 即時更新 delegate/station/國家/備註總數

## 技術棧

- 純 HTML + CSS + JavaScript（無框架依賴）
- LocalStorage 持久化備註資料
- 響應式設計（支援手機）

## 靈感來源

4-H Youth Exchange 國際交流計畫的 VPS 站點管理需求
