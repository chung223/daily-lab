# 🐟 魚油大作戰 (Fish Oil Mission)

明亮海洋風格的魚油服用追蹤工具。

## 功能特色

- 海豚督導🆚拖延鯊魚的對話大戰
- 可自訂提醒倒數計時器
- 連續天數 streak 追蹤
- 統計面板（今日/連續/總次數）
- localStorage 持久化
- 彩屑慶祝動畫

## 設計風格

- Bright Ocean/Aquarium 明亮海洋風
- 漸層海水背景 (#90E0EF→#00B4D8→#0077B6)
- 珊瑚(#FF6B6B)/金(#FFD93D)/海帶(#2D6A4F)三色
- Fredoka + Noto Sans TC 字體組合
- 漂浮泡泡動畫、搖曳海草裝飾

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可使用。
