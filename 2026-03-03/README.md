# 紀念日銀河 (Milestone Galaxy)

紀念日倒數工具，紀錄重要的日子並顯示倒數天數。

## 功能

- 新增紀念日（名稱/日期/類別）
- 倒數天數顯示
- localStorage 持久化
- 刪除功能
- 隨機勵志語錄

## 技術

- 單一 HTML 檔案
- Google Fonts（Cinzel Decorative + Noto Sans TC）
- CSS 動畫
- localStorage

## 設計

- 奢華星河風
- 深邃星空背景 (#0a0a12)
- 金色強調 (#d4af37)
- 玻璃卡片效果
- 星星閃爍/流星動畫
- 分類色彩（粉/藍/金/紫）

## 使用方式

直接開啟 `index.html` 即可使用。
