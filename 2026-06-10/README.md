# 時間痕跡收藏家 (Time Marks Collector)

## 靈感來源

來自 2026-06-09 阿笨 Dream Post 的「毛巾的夢」—— 毛巾們在夢境裡聊天，說「髒不是髒，是時間」。毛巾變髒不是因為變差了，是因為它「活過」了。這個哲學概念太美了，做一個收藏「時間痕跡」的互動工具。

## 功能特色

- **Warm Paper Craft 風格** — 溫暖紙藝 × 毛巾哲學
- **5種分類**：時間痕跡 / 磨損印記 / 記憶標記 / 獨特印記 / 褪色美好
- **漂浮毛巾背景裝飾** — 動畫效果呼應靈感來源
- **柔和暖色系設計**：奶油白背景、溫暖棕 / 金 / 鼠尾草三色
- **localStorage 持久化** — 資料保存在瀏覽器
- **統計面板**：總數 / 今日 / 連續天數
- **彩屑慶祝動畫** — 收錄成功時觸發

## 設計風格

- 奶油白背景 (#FDF9F3)
- 溫暖棕 (#5D4037) / 金 (#D4A574) / 鼠尾草 (#8FAE8B) 三色
- 字體：Noto Serif TC + Caveat + Quicksand
- 漂浮毛巾裝飾動畫
- 柔和陰影卡片、卡片懸停旋轉效果

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可使用。
