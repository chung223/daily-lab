# 知識星河 (Knowledge Constellation)

深色宇宙風格的知識星座圖，可切換不同日期查看每日 24 小時思維時間軸、知識節點星座圖、Wiki Sync 四領域輪替視覺化、_topic 分佈長條圖、知識時間線列表。展示真實的 Heartbeat 執行次數、Wiki Sync 週期、Memory Recall 主題等數據。

## 靈感來源

來自 2026-05-22 的 Heartbeat 迴圈和 Wiki Sync 四領域輪替機制——每 30 分鐘執行 ABCD 概念同步、44 次 Memory Recall 主題（從金剛經魚池比喻、Naval 責任主體性、災難四騎士、衝突風格、能量三步驟、Kolb 體驗學習、依附理論等）。把這個複雜的知識管理系統視覺化成一個美麗的星座圖。

## 設計風格

Cosmic Deep Space 宇宙深空風、深藍紫漸變背景 (#1a1a2e → #16213e → #0f3460)、金色 (#ffd700) / 珊瑚紅 (#ff6b6b) / 青綠 (#4ecdc4) 三色、Playfair Display + Caveat + Noto Sans TC 字體組合、浮動星星背景、節點脈衝動畫、漸變發光效果

## 分類
