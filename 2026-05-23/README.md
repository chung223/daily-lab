# 知識星河 — Knowledge Constellation

**分類**: 視覺化 / 個人知識管理

探索每日思維軌跡的互動式視覺化工具。將 Brain Heartbeat、Wiki Sync、Memory Recall 等系統數據轉化為美麗的星座圖、時間軸和統計面板。

## 功能特色

- 🌌 **24小時思維時間軸** — 以視覺化方式呈現一天中的知識獲取時間點
- 📊 **數據統計面板** — Heartbeat 次數、Wiki Sync 週期、Memory Recall 次數
- 🌟 **知識星座圖** — 將各主題以星座方式排列，互動式探索
- 🔄 **Wiki Sync 循環** — 展示 ABCD 四領域的輪替概念
- 📈 **主題分佈圖** — 長條圖呈現各類別知識佔比
- 📜 **知識時間線列表** — 逐筆記錄每個知識點的時間與描述
- 🌃 **星空背景** — 動態星點動畫效果

## 技術棧

- 純 HTML5 + CSS3 + JavaScript
- Canvas API（星空背景動畫）
- Google Fonts（Noto Sans TC, Caveat, Playfair Display）

## 使用方式

直接在瀏覽器中開啟 `index.html` 即可使用。支援不同日期的資料切換。
