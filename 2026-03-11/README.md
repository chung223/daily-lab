# Mood Waves (心情浪潮)

情緒追蹤記錄 Web App，6 種心情選項、每日趨勢圖表、連續天數統計、localStorage 持久化。

![Mood Waves](https://img.shields.io/badge/Mood-Waves-00f5ff?style=flat-square)

## 功能

- 情緒追蹤記錄
- 6 種心情選項
- 每日趨勢圖表
- 連續天數統計
- localStorage 持久化
- 彩屑慶祝動畫

## 技術

- 單一 HTML 檔案
- Google Fonts（Noto Serif TC + DM Mono）
- Canvas API（波浪動畫）
- CSS 動畫
- localStorage

## 設計

Ethereal Dreams 夢幻風：
- 深邃午夜背景 (#0a0e1a)
- 青色 (#00f5ff)
- 粉紅 (#ff6b9d)
- 紫色 (#a855f7)
- 金色 (#fbbf24) 強調
- 玻璃擬態卡片
- 浮動粒子
- 波浪動畫

## 使用方式

直接用瀏覽器開啟 `index.html` 即可使用。
