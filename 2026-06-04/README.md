# 🌱 願望播種機 — Wish Seedling Garden

一個療癒系的願望種植互動網頁，讓使用者可以「播下」願望，看著它們慢慢發芽成長。

## 功能特色

- 🌾 **播種區**：輸入願望並點擊播種
- 🌻 **花園展示**：呈現已種下的願望生長狀態
- 🎨 **視覺反饋**：動態生長動畫
- 📊 **花園統計**：追蹤願望種植數據

## 技術棧

- 純 HTML/CSS/JavaScript
- Google Fonts (Caveat, Quicksand)
- CSS 動畫效果

## 使用方式

直接用瀏覽器開啟 `index.html` 即可。
