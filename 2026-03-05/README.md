# ⚡ Prompt Forge - AI Prompt Optimizer

輸入原始提示詞、選擇優化風格（簡潔/詳細/創意/技術）、打字機動畫輸出、localStorage 歷史記錄、複製功能。

## 功能

- 輸入原始提示詞
- 選擇優化風格：簡潔 / 詳細 / 創意 / 技術
- 打字機動畫輸出優化結果
- localStorage 歷史記錄
- 一鍵複製結果

## 設計

- Neo-Blueprint 科技風
- 深邃 Navy 背景 (#0a0e17)
- 電光藍強調 (#22d3ee)
- 琥珀點綴 (#fbbf24)
- 網格背景 + 掃描線效果

## 使用

直接用瀏覽器開啟 `index.html` 即可使用。

```bash
# 或使用本地伺服器
npx serve .
```

## 技術

- 單一 HTML 檔案
- Google Fonts（Orbitron + JetBrains Mono + Noto Sans TC）
- CSS 動畫
- localStorage
