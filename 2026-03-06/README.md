# Neon Pong

復古霓虹乒乓球遊戲、鍵盤/滑鼠/觸控控制、粒子特效、localStorage 統計（勝場/敗場/連勝）

## 功能

- 鍵盤/滑鼠/觸控控制
- 粒子特效
- localStorage 統計（勝場/敗場/連勝）

## 技術

- 單一 HTML 檔案
- Google Fonts（Orbitron + Noto Sans TC）
- Canvas API
- localStorage

## 設計

Neon-Punk cyber 風
- 深邃黑背景 (#050508)
- 電光青 (#00fff5)
- 霓虹粉 (#ff00ff)
- 紫 (#8b5cf6) 強調
- 星空背景
- 掃描線效果
- 發光動畫

## 如何使用

直接開啟 `index.html` 即可遊玩。
