# 🏛️ 越南獨立宮時光機

**Vietnam Independence Palace Time Machine**

用報紙/博物館文件風格呈現獨立宮的 4 個時代——從法屬時期到今日博物館，包含可點擊的時間軸、視覺檔案卡片、關鍵數據面板。

## 靈感來源

2026-05-05 下午 Chung 在 Discord 詢問越南胡志明市獨立宮 (Dinh Độc Lập) 的歷史。整理了從 1868 法國殖民建造到 1975 坦克撞門的完整時間線。

## 設計風格

**Vintage Editorial Newsprint** 復古報紙文件風

- 奶油紙張背景 (#F5F0E6)
- 暖棕/鐵鏽紅/金色主色
- Playfair Display + Courier Prime + Noto Serif TC 字體組合
- 博物館文件質感與報紙排版美學

## 四個時代

1. **法屬時期 (1868-1945)** — 統一宮時期，法國殖民建造
2. **南越時期 (1955-1975)** — 阮文紹總統時代
3. **越戰終結 (1975)** — 歷史性坦克撞門事件
4. **今日博物館** — 開放參觀的歷史遺跡

## 功能特色

- 📰 可點擊的互動式時間軸
- 🗂️ 視覺化檔案卡片展示
- 📊 關鍵數據面板
- 博物館文件風格排版
