# 維基樂團 · Wiki Orchestra

A musical visualization project inspired by Wikipedia data, featuring rotating instrument cards with heartbeat statistics.

## Description

Wiki Orchestra presents a unique blend of wiki data and musical rhythm. The interface showcases four rotating instrument cards (A, B, C, D) representing different wiki-based learning systems, with real-time heartbeat statistics tracking since midnight.

## Features

- **Rotating Instrument Cards** — Four cards (A, B, C, D) cycle every 30 minutes
- **Heartbeat Statistics** — Tracks heartbeats since 00:23 at 30-min intervals
- **Progress Bars** — Visual countdown to next cycle for each instrument
- **WAIC 2026 Countdown** — Real-time countdown to the event

## Design

- Japanese Minimal × Zen aesthetic
- Cream background (#FAF6ED) with amber/gold accents (#C4903D)
- Paper texture with music staff line patterns
- Pulse halo animations on active instruments
