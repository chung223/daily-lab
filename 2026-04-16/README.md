# 🐟 魚油英雄拯救站點 (Fish Oil Rescue Squad)

> 結合 VPS 站點救援任務 × 魚油劇場經典角色的漫畫風格緊急救援遊戲

![Preview](https://img.shields.io/badge/預覽-直接開啟HTML-blue?style=for-the-badge)

## 🎮 專案說明

漫畫風格 VPS 站點救援中心，玩家扮演魚油英雄搶救故障站點。

### 核心功能
- 🖥️ **17 個站點狀態顯示**：12 正常 / 5 故障
- 🎯 **隨機救援按鈕**：一次拯救一個故障站點
- 🚀 **全部救援功能**：一鍵修復所有站點
- 📋 **救援報告生成**：可複製的救援摘要

### 特色亮點
- 🐬 海豚督導聲納定位故障站點
- 💊 拖延鯊終於行動救援
- ⚡ 速度線漫畫特效
- 💥 點擊爆發粒子動畫
- 🔴 Critical 站點閃爍警告
