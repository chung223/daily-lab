# 幾何花園 | Geometric Garden

互動式幾何圖形生成器 - 點擊或拖曳產生美麗的幾何圖形

![Preview](https://img.shields.io/badge/Neo--Crystal-晶體風-blue)
![Status](https://img.shields.io/badge/Status-Active-green)

## 功能

- **互動式生成**：點擊或拖曳產生幾何圖形
- **5 種形狀**：三角形、六邊形、圓形、菱形、星星
- **6 種色彩主題**：自由切換
- **動態連線**：圖形間自動產生連線效果
- **動畫效果**：旋轉與脈動動畫
- **還原/清除**：支援还原和清除功能
- **持久化**：localStorage 自動儲存

## 技術

- 單一 HTML 檔案（直接開啟即可用）
- Google Fonts（Orbitron + Noto Sans TC）
- Canvas API
- localStorage

## 設計

- Neo-Crystal 晶體風格
- 深邃太空背景 (#0a0a12)
- 水晶青色 (#00f5ff)
- 紫色 (#a855f7)
- 琥珀 (#fbbf24) 點綴
- 星空粒子飄移
- 玻璃擬態控制面板

## 如何使用

直接用瀏覽器開啟 `index.html` 即可使用。
