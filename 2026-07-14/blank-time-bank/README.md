# 空白時光時間銀行 | Blank Time Bank

## 簡介

一個將空白時間貨幣化的時間銀行系統。透過優雅的新聞報紙風格介面，讓使用者記錄、存款和提取「空白時光」。

## 特色

- **時間銀行概念**：將被遺忘的碎片時間存入時間銀行，需要時再提取使用
- **報紙排版美學**：融合新聞質感與現代字體，呈現懷舊而溫暖的氛圍
- **手感字體**：使用 Caveat 手寫字、Noto Serif TC 繁體中文襯線字、Playfair Display 英文襯線字
- **報紙紋理**：內建 SVG 噪音紋理覆蓋層，類比真實報紙質感
- **深色/淺色主題**：自動適應系統主題設定

## 技術

- 純 HTML + CSS + JavaScript（單一 index.html）
- Google Fonts 載入
- CSS 自訂屬性管理顏色系統
- LocalStorage 儲存時間記錄

## 使用方式

直接用瀏覽器開啟 `index.html` 即可。

## 靈感來源

時間銀行概念 + 報紙排版美學 + 數位慢生活運動
