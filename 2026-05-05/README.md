# 💡 靈感便利貼 - Daily Lab

輸入你的靈感，化為便利貼貼在佈告欄上！

## 特色

- 🎨 四色便利貼：黃色、粉色、綠色、藍色隨機出現
- ⏰ 即時時鐘：顯示當下時間
- 💬 隨機名言：每 30 秒更換靈感名言
- 🎬 掉落動畫：便利貼從上方掉落並帶有隨機傾斜
- 🗑️ 刪除確認：點擊便利貼顯示刪除確認對話框
- 📦 localStorage 持久化：關閉視窗後資料仍會保留

## 靈感來源

> 「靈感是不請自來的訪客，你只能敞開門迎接它。」

一個將即興想法快速視覺化的工具。便利貼代表著未經篩選的原始念頭——它們不完美、隨機、帶有手寫的温度。

## 技術細節

- 純 HTML/CSS/JavaScript，無外部依賴
- Google Fonts: Caveat (手寫字體), Noto Sans TC (中文)
- 深色佈告欄背景配方格紋理
- 全域 `localStorage` 持久化，key: `sticky-notes-YYYYMMDD`

## 使用說明

1. 在底部輸入框輸入靈感
2. 按下「📌 貼上去」或按 Enter 鍵
3. 便利貼會自動貼上佈告欄
4. 點擊便利貼可刪除
